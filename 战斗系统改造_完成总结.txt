## 🎮 战斗系统新特性

### 战士 - 势能爆发
```
打法: 冲锋→雷霆一击→顺劈斩→旋风斩(60势能爆发)
特点: 势能越高越强，闲置会衰减，保持进攻
```

### 法师 - 充能爆发
```
打法: 火球术x3→炎爆术(瞬发高伤)
     寒冰箭x3→冰枪术(瞬发+减速)
特点: 双路线，火焰爆发/冰霜控制
```

### 盗贼 - 连击循环
```
打法: 暗影突袭(背后2点)→割裂(背后3点)→剔骨(5点终结)
特点: 位置判定，背后额外连击点
```

### 牧师 - 双标记
```
打法: 神圣之火x2→苦修(3圣光标记爆发)
     心灵震爆x2→暗言术灭(3暗影标记斩杀)
特点: 双路线，标记增强治疗/伤害
```
