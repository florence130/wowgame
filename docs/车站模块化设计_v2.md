# 晴岚港中央车站 · 模块化重设计 v3

> 取代 `Tripo3D_模型需求.md` 第 21 项「中央车站」。
> 目标：**小体量 + 少模块 + 可拼接 + 可进入室内 + 洛奇M 手绘平涂**。
> 参考：`1791173880041.png`（Vittoriano 模块库分层法）、`1791174076026.png`（街景风格）、`1791174047554.png`（原车站，已作废）。

## 变更史

| 版本 | 改动 | 触发 |
|---|---|---|
| v2 | 从旧车站（34×34 双塔多穹顶）改为模块化 L/M/S 分层，21 模块 | 用户要求可拼接 + 可进室内 |
| v2.1 | **21 → 12 模块**；主站 **20×12 → 16×8 m**；钟塔 20 → 16 m | 「21 个太碎了」「要缩小规模」 |
| **v3** | **风格语汇换为洛奇M 平涂色块**（去新古典精密感）；**配色全改回晴岚港色板**（去象牙白与大量金饰）；柱子加粗去密齿饰、檐口加厚 | 「保持洛奇M 的手绘卡通色块多边形美术风格，去除光照」「全改回晴岚港色板」 |

> ⚠️ **v3 只改风格与配色，不改模数与尺寸**——§1 的模数系统、§3 的模块清单与尺寸、§4 的拼装形态全部沿用 v2.1。
>
> **风格依据**：`docs/美术风格规范_洛奇M平涂.md`（本项目美术的唯一规范，含色板 hex、提示词模板、验收清单）。

## 1. 模数系统（拼接的前提）

| 项 | 取值 |
|---|---|
| 网格 | **4.0 m**（开间宽 = 进深 = 层高） |
| 墙厚 | **0.30 m** |
| 层高 | 4.0 m 结构 + 0.4 m 楼板 = 4.4 m 层间距 |
| 原点 | 每个模块**底面中心**（塔、灯柱为底面中心；线性件为端面中心） |
| 朝向 | **正面朝 −Z**（Godot 前方） |
| 接缝 | 相邻模块在网格线上**零间隙对拼**，柱中心恒在网格交点 |
| 允许误差 | 模块级 ±2%，整站 ±10% |

> 守住「4 m 网格 + 0.3 m 墙厚 + 底面中心原点」三条，任何模块都能互换位置。

## 2. 风格定调：洛奇M 手绘平涂（v3 重写）

**三条铁律**：无光照 · 平涂色块 · 低多边形。详见 `美术风格规范_洛奇M平涂.md`。

### 2.1 骨架（简化后的古典，不是精密新古典）

v2 的科林斯凹槽柱＋密齿饰＋尖角山花属于"精密新古典"，与洛奇M 的粗壮随意语汇冲突。v3 的处理：

| 构件 | v2（作废） | **v3** |
|---|---|---|
| 柱子 | 细长凹槽科林斯柱，高宽比 1:9 | **加粗短柱**，高宽比 1:6，凹槽简化成 4–6 道粗槽或无槽圆柱 |
| 柱头 | 科林斯茛苕叶密雕 | **简化涡卷/圆枕**，用 2–3 个色块示意 |
| 檐部 | 齿饰密排＋多层线脚 | **加厚挑檐＋一条深色檐下块**，齿饰减到每开间 5–6 个粗齿 |
| 山花 | 尖锐三角＋浮雕 | **钝角山花**，中央嵌一块以太水晶，不做浮雕 |
| 穹顶 | 铜绿肋穹顶＋金采光亭 | **蓝灰板岩穹顶＋铜绿采光亭**，去金饰 |
| 基座 | 米色细砌石 | **砂岩粗砌块**，倒大圆角，砌缝加宽 |
| 开间比 | 1 : 1.15 | **1 : 1.05**（更矮墩） |

### 2.2 魔法构件（长在骨架上，用量克制）

| 部件 | 做法 |
|---|---|
| 以太水晶 | 山花中央、檐角、灯柱顶嵌**发光菱形晶体**，材质 `_emit`，青蓝 `#5FD3E0` —— **全站唯一自发光** |
| 符文饰带 | 檐带每 2 m 嵌**符文石**，平涂色块＋细发光线，不做浮雕 |
| 悬浮环 | 穹顶上方悬浮 1 个**铜绿**细环（原金环改铜绿，独立网格慢转） |
| 金属 | 一律**铜绿**，**不用金色**（v2 的金饰全部去掉，避免画面发金发亮） |
| 木构 | 入口双扇大门、雨棚骨架用**深棕木筋**，外露粗梁与托架 |

### 2.3 配色 —— 全改回晴岚港色板

| 用途 | hex | 替换掉 v2 的 |
|---|---|---|
| 屋顶/穹顶（板岩） | `#6E7C93` / 深 `#5A6879` | ← 铜绿 `#4A7C8C` 大屋面 |
| 墙体（奶油灰泥） | `#EFE7D6` / 阴面 `#DCD0BA` | ← 象牙白 `#F2EDE3` |
| 木构（深棕木筋） | `#5A4331` / 亮 `#765B42` | ← 新增（v2 无木构） |
| 基座（砂岩） | `#C8B79B` / 阴 `#AE9C80` | ← 米色粗石 `#D9C7A8` |
| 铜绿点缀 | `#5E9B8B` | ← 铜绿 `#4A7C8C`（降饱和，只作点缀） |
| 红砖点缀 | `#A85C46` | 烟囱、局部 |
| 苔痕 | `#6E8A4A` | 屋脊、墙根 |
| 以太光 | `#5FD3E0` `_emit` | ← `#4FD8E8` |
| ~~金色~~ | ~~`#C9A227`~~ | **删除** |

> 判定标准：整站缩到拇指大小，**不应该看到任何金色的闪光点**。铜绿只出现在穹顶采光亭、雨棚骨架、灯柱三种构件上。

## 4. 拼装形态

### 形态 A · 主站（16 × 8 m）

```
                正面（−Z）
   [L-04] [L-01] [ L-02 入口 ][L-01] [L-04]        ← 一层，共 4 开间 = 16 m
   [L-04] [L-01] [ L-02 入口 ][L-01] [L-04]        ← 二层（入口体块自带两层）
   …………………………… [M-01] [M-01] ……………………………          ← 屋顶，沿进深 2 段
   进深 2 开间 = 8 m：前 4 m 大厅（通高 8 m），后 4 m 候车 + 楼梯
   钟塔：右后角，L-03 一件（高 16 m）
   [M-02 雨棚 ×2] 沿站台面单侧拼接
```
檐高 8 m，钟塔 16 m。**占地 128 m²（原 240 m²）**。

### 形态 B · 支线小站（8 × 8 m）

2 开间：`L-02` 入口 + `L-01` 一开间，屋顶 `M-01` × 1，**不带二层**、塔只留下半段。
同一批模块，砍掉一半即可。

### 形态 C · 站台加长

沿 −Z 追加 `M-02 canopy_bay`，每段 4 m、+0.6k 面；沿 ±X 追加 `L-01`/`L-04`，每开间 4 个模块。

## 5. 室内方案（"可以进入"怎么实现）

进得去的关键**不是**加 Interior 场景，而是：**外壳本身空心、墙有 0.3 m 厚度、拱窗门洞是穿透的洞。**

| 需求 | 模块 | 要点 |
|---|---|---|
| 一层／二层地板 | `I-01` | 4×4 平铺；下表面做格状顶棚 |
| 房间隔断 | `I-02` | 双面材质；0.3 m 厚；门洞与外壳大门对齐 |
| 上下楼 | `I-03` | 4 m 宽单跑，靠后墙，占 1 开间 |
| 采光 | `L-01` 高窗 + `P-03` 以太灯 | 高窗是**真洞**，自然光进得来 |
| 空间 | — | 一层大厅 4 开间 × 1 进深 = **16×4 m 通高 8 m**；后侧 4 m 为候车区 + 楼梯间 |

> **给 Tripo3D 的硬要求**：`L-01 / L-02 / L-04` 的拱与门必须是**穿透的洞**，描述里写死
> `hollow penetrating openings, no glass filling`，否则模型会把洞封死。
