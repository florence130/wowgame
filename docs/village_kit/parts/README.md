# 村屋复杂构件库（Blender 十手法手建，取代 Tripo 的整体转换）

`tools/blender/village_kit/parts.py` + `build_parts.py` → `assets/models/village_kit/parts/*.glb`（+ `parts.json` 尺寸 / 面数 / 所用手法），预览 `docs/village_kit/parts/`。

为什么不用 Tripo：把总图一次转 3D 得到的是**一个 27k 面的融合网格**（13 件压成一块板、无贴图），件间不分离、左右不对称、灌木 / 藤蔓变成硬质球块，无法当构件库用。

做法：左右对称件只建一半再 **镜像**，重复件 **阵列**（石块、板条、栅栏条、瓦层），轮廓件 **截面挤出**，圆形件 **旋绕**，墙洞用 **桥接**，边框 / 藤蔓 / 铁艺用 **曲线倒角**，顶点微扰做手作感；植被是**叶片 / 草叶软卡片**（实体化薄板，叶片按黄金角螺旋排布），不是硬块。真实米制（门 2.4×3.8m），原点在底面中心（墙类在洞口底边中点），外立面朝 -Y（导出后 +Z）。
