# 成就系统

2026-10-08。数据 `src/data/data_achiev.gd`、逻辑 `src/core/achieve.gd`、界面 `src/ui/win_achiev.gd`。
入口：底栏「成就」按钮 / Y 键。窗口左侧分类、右侧条目，顶部是总点数与完成度。

## 规则

- **点数**：每条成就给固定点数（5 / 10 / 15 / 20 / 25 / 30），达成时累加并广播（聊天 + 中央提示 + 音效）。
- **奖励**：条目可带 `reward = {"money": 铜, "items": [[物品id, 数量]]}`，达成**即刻**结算进背包/钱包（不像邮件那样要领取）。
- **隐藏成就**：`hidden = true` 的条目在达成前不出现在列表里（阵亡类）。
- **元成就**：`kind = "points"` 的条目看累计点数，因此每次解锁都会连带重判一次（判定循环跑到稳定，且带防重入）。
- **存档**：`pd["achiev"] = {"done": {id: 达成天数}, "stats": {统计键: 计数}, "pts": 累计点数}`。
  老存档在 `Game.load()` 里补 `achiev` 键（结构在首次判定时自动建立），**不重算历史进度**，也不升存档版本。
  GM 命令：`/gm achiev`（查看进度）、`/gm achiev reset`（清空）。

## 分类与判定方式

| 分类 | 条目数 | 判定方式 |
|---|---|---|
| 成长 | 10 | 等级、技能数、天赋点、配方数、点数元成就 |
| 任务 | 6 | 完成任务数、主线任务数 |
| 战斗 | 13 | 击杀总数 / 精英 / 稀有命名 / 首领、逐只首领、阵亡数 |
| 探索 | 8 | 已发现地点数、具体地点（`poi_abbey` / `poi_solenne` / `poi_sanctum_in`）、飞行点 |
| 专业与经济 | 13 | 已学专业数、制造数、采集数、交易所成交、持币峰值、来信数 |
| 声望 | 7 | 某阵营点数、任一阵营最高（`rep_any`）、五阵营最低（`rep_all`） |

`kind` 取值：`stat`（统计键）、`kill`（某怪物击杀数）、`level`、`rep` / `rep_any` / `rep_all`、`explored` / `poi`、
`spells` / `talents` / `profs` / `recipes`、`money`（持币峰值）、`points`、`fps`。

统计键（由玩法钩子累加）：`quests`、`quests_main`、`kills`、`elites`、`rares`、`bosses`、`deaths`、`craft`、`gather`、
`auction_sold`、`fps`、`mails`、`money_peak`。

## 接入点

| 位置 | 作用 |
|---|---|
| `Game.turn_in_quest()` | 任务完成 → `quests` / `quests_main` |
| `Game.on_kill()` | 击杀 → 总数 / 精英（elite）/ 稀有命名（rare/named）/ 首领（boss） |
| `Game._on_level_up()` | 升级后重判等级类 |
| `Game.add_money()` | 记录持币峰值（花掉不回落） |
| `Game.rep_changed` | 声望变化后重判声望类（在 `Game._ready` 里连接） |
| `Game.discover_fp()` | 飞行点 → `fps` |
| `zone.gd::_on_poi()` | 写入 `pd["explored"]` 之后重判探索类 |
| `player.gd::_on_death()` | 阵亡 → `deaths` |
| `Prof.finish_craft()` | 制造完成 → `craft` |
| `GatherNode._complete()` | 采集成功 → `gather` |
| `Auction.tick()` | 挂单成交 → `auction_sold` |
| `Mail.deliver()` | 收到系统来信 → `mails` |
| `hud.gd` | 窗口注册、底栏按钮（第 5 位，Y）、`WIN` 键位表 |

## 边界

- 只作用于玩家；同伴与怪物的战斗不计入成就。
- 未做：成就统计页（合并到别的窗口）、成就点数的实质用途（购买/解锁名号）、按成就解锁的称号与战袍、
  限时/赛季成就、成就分享。
- 「首次击杀某只首领」用的是 `pd["kills"]`，而副本首领不刷新（`respawn = 0`），所以那三条是按真实首杀判定的。
