# 战斗系统改造 - 快速入门

## 🎯 核心变化

### 所有技能改为0消耗
- 不再消耗法力/怒气/能量
- 改为使用职业专属资源系统

### 四大职业资源系统

#### 1️⃣ 战士 - 势能(Momentum)
```
基础机制：
  • 攻击技能产生势能 (30-40点)
  • 爆发技能消耗势能 (需要60-80点)
  • 闲置3秒后开始衰减 (20点/秒)
  • 最大100点

打法循环：
  冲锋(+30势能) → 雷霆一击(+30) → 顺劈斩(+30) 
  → 达到60势能 → 旋风斩(消耗爆发)
```

#### 2️⃣ 法师 - 双充能(Fire/Frost)
```
基础机制：
  • 火球术产生火焰充能
  • 寒冰箭产生冰霜充能
  • 各最多5层
  • 消耗技能需要≥3层充能

打法循环：
  火焰路线：火球术(x3) → 炎爆术(瞬发爆发)
  冰霜路线：寒冰箭(x3) → 冰枪术(瞬发+减速)
  混合路线：火+冰(x3) → 奥术冲击(高伤害)
```

#### 3️⃣ 盗贼 - 能量+连击点
```
基础机制：
  • 能量自动恢复 (10点/秒)
  • 生成技能消耗能量，产生1-3连击点
  • 终结技消耗所有连击点
  • 最多5连击点

打法循环：
  毒刃(30能量,+1点) → 割裂(50能量,+2点) 
  → 达到5连击点 → 剔骨(终结技,返还能量)
  
位置加成：
  • 背后使用割裂：2点→3点
  • 暗影突袭：自动瞬移背后
```

#### 4️⃣ 牧师 - 双标记系统
```
基础机制：
  • 圣光标记(holy_mark) - 增强治疗
  • 暗影标记(shadow_mark) - 增强伤害
  • 各最多5层，持续30秒
  • 消耗技能需要≥3层标记

打法循环：
  圣光输出：惩击(+1) → 神圣之火(+2) → 苦修(消耗爆发)
  暗影输出：暗言术痛(+1) → 心灵震爆(+2) → 暗言术灭(斩杀)
  治疗增强：堆圣光标记 → 快速治疗(每层+60治疗量)
```

## 🆕 新增系统

### 闪避与耐力
- 耐力上限100点
- 闪避消耗30点
- 连续闪避递增消耗（+20/次）
- 不闪避时自动恢复（25点/秒）

### 位置判定
- **背后**：目标背后120度扇形范围
- **侧面**：目标左右各90度扇形范围
- 部分盗贼技能需要位置要求

### 连招链
- 某些技能释放后设置连招标记
- 后续技能可要求特定连招链
- 连招窗口4秒

## 🎮 实战技巧

### 战士
1. 起手冲锋积累势能
2. 用雷霆一击→顺劈斩打连招
3. 势能≥60时释放旋风斩
4. 势能≥80时用狂暴打击爆发
5. 目标低血时用致死打击斩杀

### 法师
1. 选择路线：火焰爆发 / 冰霜控制 / 混合输出
2. 火球术x3 → 炎爆术（瞬发）
3. 或寒冰箭x3 → 冰枪术（减速）
4. 火焰爆发状态下用烈焰风暴AOE
5. 混合充能可用奥术冲击清空

### 盗贼
1. 潜行起手暗影突袭（瞬移背后+2点）
2. 走位到背后，用割裂（+3点）
3. 5连击点时释放剔骨
4. 保持毒刃DOT（可叠3层）
5. 控制时用肾击

### 牧师
1. 双路线：圣光输出 / 暗影输出
2. 圣光：惩击+神圣之火堆标记 → 苦修爆发
3. 暗影：暗言术痛+心灵震爆堆标记 → 暗言术灭斩杀
4. 精神鞭笞在有暗影标记时伤害高
5. 治疗时先堆圣光标记增强效果

## ⚠️ 注意事项

### 资源管理
- 战士：不攻击会衰减势能，保持进攻
- 法师：充能分类型，选对路线
- 盗贼：能量有上限(100)，不要溢出
- 牧师：标记30秒过期，及时消耗

### 位置意识
- 盗贼背后伤害高，尽量绕背
- 暗影突袭可快速到背后
- 闪避后注意重新定位

### 耐力控制
- 闪避消耗耐力，不要连续闪避
- 耐力不足时无法闪避
- 安全时留耐力应急
