# 晴岚港主城漫游与编辑

打开同目录的 **晴岚港-主城漫游.html**。模型、地形和页面程序都在这一个文件中，不依赖网络下载资源。建议使用较新的 Chrome、Edge 或 Firefox。

1. **看全城**：左键拖动环绕，右键拖动平移，滚轮缩放。“全城”恢复总览；“前往地标”快速定位。
2. **走进街道**：点击“步行漫游”，再点击画面。W A S D 或方向键行走，Shift 加速。支持锁定鼠标时直接转向，Esc 释放鼠标；若浏览器限制锁定，按住左键拖动转向。右下按钮也可行走与转向。“鸟瞰编辑”回到编辑视角。
3. **调整建筑**：点击画面中的建筑，或从目录中选择。右侧可改位置、朝向和地基标高，也可用“拖动”“旋转”手柄。复制、隐藏、删除都可撤销。
4. **调整整个街坊**：在目录的街坊菜单中选择“河湾西街坊”等分组，再点“选择整个街坊”。输入东西/南北位移后点“平移所选建筑”，或输入角度后点“旋转所选建筑”。整组保留相对间距；院落与出口的分组记录会随之调整。也可按住 Ctrl/⌘ 多选建筑。
5. **看地面与街坊分配**：新版“地面审查”隐藏建筑与装饰，显示预留地界、建筑占地、入口和街坊步行网，保留真实道路、人行道与台阶。此模式仅供查看；退出后可继续编辑建筑。道路位置与宽度仍可制作草稿；台地改为只读，由统一总图调整，旧草稿参数保留导出。
6. **撤销与保存**：顶部“撤销/重做”或 Ctrl+Z / Ctrl+Y 可回退。浏览器允许时，草稿会自动保存在本机同版本页面下；“还原原始布局”也可撤销。窄窗口用顶部“目录”“调整”打开面板，点“收起”可让出画面。
7. **导出交回项目**：点击“导出改动”，选择“下载 JSON”。如果内置浏览器未显示下载，可点击“复制完整 JSON”。文件含完整布局、改动记录和来源版本，便于回导；“导入草稿”可继续同版本编辑。

**网页草稿不会自动应用到游戏。** 要采用修改，请把导出的 JSON 交回此项目，按来源版本核对后更新布局，再生成城市并复验道路、地基、碰撞和角色通行。道路彩色带仅表达草稿，台地轮廓仅供审阅，网页步行也不代替游戏里的完整角色碰撞系统。

同一份草稿只能直接导入同一基线版本的 HTML。城市更新后，旧草稿不会自动覆盖新版；保留旧 HTML 与 JSON，便于比较和迁移修改。

旧gen11d版已实际验证通过本机网页地址载入、街坊选择/位移/撤销以及 JSON 文件导出。页面的所有资源均已内嵌；浏览器自动化的 `file://` 协议受到限制，因此没有把“自动双击打开”记为已实测。系统浏览器正常双击打开的兼容性仍以实际使用为准。
