# 战斗系统重构方案：半动作化改造

**制定时间**：2026-10-12  
**目标**：将当前站桩式战斗改造为中速节奏的半动作MMORPG，参考剑灵/TERA/FF14。

---

## 一、核心战斗框架改动

### 1.1 节奏调整
- **保留1.5秒GCD**，但引入**瞬发技能**不触发GCD
- **快速技能**（0.5-0.8秒GCD）作为连招起手
- **资源技能**（消耗连击点/能量/怒气）瞬发或短CD

### 1.2 连招链系统（Combo Chain）
新增`combo_chain`状态，记录当前连招进度：

```gdscript
# Unit 新增字段
var combo_chain := ""        # 当前连招链ID（如"warrior_rage_1"）
var combo_window := 0.0      # 连招窗口剩余时间（3-5秒）
var combo_charges := 0       # 通用连击计数（替代现有combo）
```

**机制**：
- 技能A命中后，设置`combo_chain = "skill_a_hit"`，`combo_window = 4.0`
- 技能B检查`requires: {"combo_chain": ["skill_a_hit", "other_chain"]}`
- 命中技能B后，链条延续或转换：`combo_chain = "skill_b_hit"`
- 超时或被打断，链条重置

**整合按键**（参考FF14武士）：
- 同一按键在不同连招阶段触发不同技能
- UI显示当前可用的下一步技能（高亮/脉冲）

### 1.3 方向输入系统
技能检查`directional_input`字段：

```gdscript
# 技能定义示例
"dodge_roll": {
    "directional": true,  # 启用方向输入
    "forward": {"effects": [...]},   # 前滚翻
    "backward": {"effects": [...]},  # 后撤步
    "left": {"effects": [...]},      # 左闪
    "right": {"effects": [...]},     # 右闪
}
```

施法时读取玩家输入方向（WASD），选择对应效果分支。

### 1.4 闪避系统
**通用机制**（所有职业）：
- 新增**耐力**资源（Stamina，独立于生命/法力/怒气/能量）
- 初始100点，战斗中每秒回复10点，脱战每秒20点
- **闪避**消耗30耐力，0.8秒无敌帧 + 位移8码，CD 2秒
- 连续闪避递增消耗（30 → 50 → 80），3秒后重置

**职业特化**：
- **战士**：格挡（盾牌职业）消耗20耐力，减伤70%并反击
- **盗贼**：影步消耗25耐力，瞬移12码留下残影
- **枪手**：后坐跃现在消耗耐力，成为通用机动

### 1.5 格挡/弹反系统（战士/盗贼专属）
**战士-防护专精**：
- **格挡**（主动）：0.5秒窗口，成功格挡触发**盾击**（免费瞬发反击）
- **完美格挡**：攻击命中前0.2秒内格挡，触发**盾墙反击**（眩晕敌人1秒）

**盗贼-战斗专精**：
- **招架**（被动）：双持武器时5%几率触发，下一次攻击瞬发且伤害+50%

## 二、职业全新设计

### 2.1 战士（Warrior）—— 势能系统

**核心机制**：**势能（Momentum）**替代怒气
- 最大100点，战斗外归零
- **蓄力攻击**每次+15势能（1秒GCD）
- **爆发技**消耗势能，威力与消耗量成正比
- 高势能时移动速度+10%，攻击速度+5%

**武器专精**（主输出）：
1. **蓄势斩**（起手）→ +15势能，1秒GCD
2. **破甲斩**（连招）→ 蓄势斩命中后3秒内可用，+20势能，降低目标护甲
3. **致命打击**（终结）→ 消耗50势能，巨额伤害
4. **旋风斩**（AOE）→ 消耗30势能，周围8码敌人

**连招循环示例**：
```
蓄势斩(+15) → 破甲斩(+20) → 蓄势斩(+15) 
→ 势能50 → 致命打击爆发 → 重复
```

**防护专精**（坦克）：
- **盾墙姿态**：受到伤害+10势能
- **盾击**：消耗20势能，高威胁
- **守护者之怒**（大招）：100势能爆发，8秒内伤害-40%且每次格挡回复5%生命

---

### 2.2 法师（Mage）—— 元素充能

**核心机制**：**火焰/冰霜充能**（Fire/Frost Charge）
- 两种独立充能，各0-3层
- **火焰技能**消耗火焰充能，生成冰霜充能
- **冰霜技能**消耗冰霜充能，生成火焰充能
- **奥术技能**消耗两种充能，触发爆发

**火焰分支**：
1. **火球术**（生成）→ 1.5秒施法，+1火焰充能
2. **烈焰冲击**（消耗）→ 瞬发，消耗1火焰充能，高伤害
3. **炎爆术**（大招）→ 消耗3火焰充能，3秒引导，巨额AOE

**冰霜分支**：
1. **寒冰箭**（生成）→ 1.2秒施法，+1冰霜充能，减速
2. **冰锥术**（消耗）→ 瞬发，消耗1冰霜充能，定身3秒
3. **暴风雪**（大招）→ 消耗3冰霜充能，范围持续伤害

**奥术爆发**：
- **奥术洪流**：消耗1火焰+1冰霜，瞬发，中等伤害无CD
- **元素湮灭**：消耗3火焰+3冰霜，终极爆发

**循环示例**：
```
火球(火+1) → 火球(火+2) → 火球(火+3) 
→ 烈焰冲击(火-1,冰+1) → 寒冰箭(冰+2,火+1) 
→ 冰锥(冰-1,火+2) → 循环
```

---

### 2.3 牧师（Priest）—— 圣言/暗言双态

**核心机制**：**圣言值/暗言值**（0-100）
- 同一时间只有一种主导
- **神圣技能**增加圣言值，减少暗言值
- **暗影技能**增加暗言值，减少圣言值
- 达到100时进入**圣光/暗影形态**（15秒）

**神圣分支**（治疗/辅助）：
1. **圣光术**（快速治疗）→ +10圣言
2. **恢复**（HOT）→ +5圣言/跳
3. **圣光爆发**（群疗）→ -20圣言，范围治疗
4. **圣光形态**（100圣言）→ 所有治疗+30%，15秒

**暗影分支**（输出）：
1. **暗影箭**（主要输出）→ +15暗言
2. **心灵震爆**（爆发）→ +25暗言，CD 8秒
3. **吸血鬼之触**（DOT）→ +5暗言/跳，吸血
4. **暗影形态**（100暗言）→ 所有伤害+30%，免疫控制，15秒

**切换策略**：
- 治疗时维持60+圣言值，避免掉到暗影侧
- 输出时堆满暗言进形态爆发
- **心灵鞭笞**（平衡技）：重置双值到50

---

### 2.4 盗贼（Rogue）—— 连击点重构

**核心机制**：保留**连击点**（Combo Points），但加入**影刃标记**
- 影刃标记：生成技能在目标身上标记，持续8秒
- 终结技威力与**标记层数**成正比（而非连击点）
- 连击点用于解锁特殊技能

**刺杀专精**：
1. **毒刃**（生成）→ +1连击点，+1影刃标记
2. **割裂**（终结）→ 消耗3连击点，持续伤害按标记层数
3. **剧毒新星**（爆发）→ 5连击点+5标记，巨额伤害

**战斗专精**（方向输入）：
1. **影袭**（方向技）：
   - **前**：突进5码，+2连击点
   - **后**：后撤3码，+1连击点+闪避1秒
   - **左/右**：侧滑，下次攻击暴击
2. **乱舞**（终结）→ 5连击点，0.5秒内连击5次

**循环示例**：
```
毒刃(点+1,标+1) → 毒刃(点+2,标+2) → 毒刃(点+3,标+3)
→ 割裂(消耗3点,按3标记算伤害) → 重复
```

---

### 2.5 魔导枪手（Gunner）—— 过热系统

**核心机制**：**热量（Heat）**替代法力
- 最大100点，自然冷却每秒-10
- **射击技能**产生热量（10-30）
- 超过80热量：射速+20%但精准-10%
- 达到100：**过载**，强制冷却3秒不能攻击

**射击专精**：
1. **稳固射击**（基础）→ +5热量，低伤害
2. **速射**（连发）→ +15热量/发，1秒内3发
3. **狙击**（蓄力）→ +30热量，2秒引导，高伤害
4. **冷却剂**（管理）→ -50热量，瞬发，CD 20秒

**生存专精**（近战+机动）：
1. **刺刀突刺**（近战）→ +10热量，5码突进
2. **后坐跃**（位移）→ 消耗30耐力，12码后跃
3. **地雷陷阱**（控制）→ +5热量，布置陷阱
4. **紧急过载**（爆发）→ 热量清零，下3次攻击免费

**循环示例**（热量管理）：
```
稳固(5) → 速射(45) → 稳固(50) → 狙击(80,加速区)
→ 冷却剂(-50=30) → 继续
避免到100过载
```

## 三、转职系统与技能分类

### 3.1 15级转职系统
**基础职业**（1-14级）：
- 战士 → 15级选择：**武器大师** / **不屈卫士** / **狂战士**
- 法师 → 15级选择：**元素使** / **奥术学者** / **时空法师**
- 牧师 → 15级选择：**圣言者** / **暗影祭司** / **戒律行者**
- 盗贼 → 15级选择：**刺客** / **剑舞者** / **影行者**
- 枪手 → 15级选择：**神射手** / **机械师** / **赏金猎人**

**转职效果**：
- 解锁专精专属技能（3-5个）
- 解锁1个被动特性
- 调整基础资源机制参数

### 3.2 技能分类系统（替代天赋树）

**主动技能（Active Skills）**：
- 需要手动释放
- 占用技能栏位
- 有CD、消耗、施法时间
- 例：`"type": "active"`

**被动技能（Passive Skills）**：
- 永久生效
- 不占技能栏
- 转职/升级自动习得
- 例：`"type": "passive"`, `"effects": [{"passive_stat": "crit", "value": 5}]`

**特性（Traits）**：
- 改变其他技能行为
- 条件触发效果
- 例：`"trait_id": "warrior_enrage"`, `"trigger": "below_30_hp"`, `"effect": "dmg_done +20%"`

**技能定义示例**：
```gdscript
# 主动技能
"mortal_strike": {
    "type": "active",
    "name": "致死打击",
    "requires_spec": "weapon_master",  # 武器大师专精专属
    "cost": 50,
    "cd": 6.0,
    # ...
}

# 被动技能
"weapon_mastery": {
    "type": "passive",
    "name": "武器精通",
    "spec": "weapon_master",
    "level": 15,  # 转职时习得
    "effects": [{"passive_stat": "ap_pct", "value": 0.1}]
}

# 特性
"berserker_rage": {
    "type": "trait",
    "name": "狂战士之怒",
    "spec": "berserker",
    "trigger": "hp_below_pct",
    "trigger_value": 0.3,
    "effects": [{"mod": "dmg_done", "value": 0.25}, {"mod": "dmg_taken", "value": 0.15}]
}
```

### 3.3 成长路线
```
等级1：基础职业，3-4个起始技能
等级4-6：解锁核心循环技能（2-3个）
等级8-10：解锁位移/控制技能（1-2个）
等级12-14：解锁资源管理技能
等级15：转职，解锁专精技能+被动+特性
等级16-20：逐步解锁专精高级技能
```

**天赋系统移除**，技能成长完全由等级+转职决定。

## 四、UI/打击感改进

### 4.1 连招提示
- 屏幕中央显示**下一步可用技能**图标（脉冲高亮）
- 技能按键整合：同一键位根据连招状态触发不同技能
- 连招窗口倒计时条

### 4.2 资源显示
- **战士**：势能条（黄色，0-100）
- **法师**：双充能球（火焰/冰霜，各0-3层）
- **牧师**：圣暗双值条（渐变，中央50为平衡点）
- **盗贼**：连击点+影刃标记层数
- **枪手**：热量条（绿→黄→红，80+变色）

### 4.3 打击感强化
- **屏幕震动**：暴击/终结技触发轻微震动
- **时间减速**：完美格挡/弹反触发0.2秒子弹时间
- **连招音效**：每一段连招有独特音效，成功连携时和弦

## 六、风险与备选

### 风险1：复杂度爆炸
**现象**：5职业×3专精×10技能=150+技能数据  
**缓解**：
- 优先完成战士（试点）
- 共享通用技能（闪避、基础攻击）
- 用连招链减少技能栏占用

### 风险2：现有存档兼容
**决策**：不保留旧版战斗系统，允许破坏存档  
**措施**：
- 登录时检测版本号，旧存档强制重置技能/属性
- 提示玩家"战斗系统已重构，角色已重置"

### 风险3：AI跟不上节奏
**现象**：玩家可以无伤风筝怪物  
**方案**：
- Boss免疫连续控制（递减效果）
- 远程怪增加突进技能
- 精英怪也有闪避/格挡
