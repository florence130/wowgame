# 昼夜、植被、水面与体积光接入

项目为 Godot 4.7 Forward+。Unity URP 的 ShaderGraph、C# RendererFeature 不能在本引擎原样运行，本次使用指定资源的原始纹理、模型与着色算法做 Godot 适配。原始 F 盘资源没有改动。

| 来源 | 实际运行接入 |
|---|---|
| Super Simple Skybox 5.0.0 | 云形纹理两层、星图；天空渐变、太阳/月亮、风速与云覆盖；取消旧白昼全景图，避免接缝。昼夜与方向光共用方向。 |
| Cartoon Grass and Plants 1.01 | Grass_04-1 草簇、Flower_01–04、Plant_01/07/10；GLB 网格保留 UV/调色板。迁移 Grass/Vegetation/Flowers 的根梢渐变、顶点高度风摆、世界位置偏移、透明裁剪与远景简化。 |
| Stylized Water For URP 1.1.2 | 原始法线、泡沫、焦散纹理；移植 Gerstner 波、双层法线、扭曲泡沫、岸线相交与深浅颜色。海洋、地形水、模型道具水、程序道具水和角色选择界面统一绑定。 |
| Ethereal URP 1.6.5 | 原始雾噪声；移植高度衰减、流动噪声与密度调制。光积分、阴影采样和各向异性散射使用 Godot 原生体积雾，形成实际遮挡后的阳光光束。 |

草的根部从所属地形材质取得控制图、草地纹理、图层颜色、世界坐标与宏观噪声；花瓣保留原资源花色。近处间距 0.54 → 0.40 米，远处 0.95 → 0.72 米。密度仍排除建筑、道路、石板、沙滩、水下和陡坡；不增加玩家压草行为。花草使用 MultiMesh 分批绘制和 24 米分块流式加载。

天气按晴、阴、雨、雷暴、雾各自的目标云量、降雨、雾密度、风力、遮光量分别缓动（时间常数 6 秒）。所有效果共用此连续状态；转晴或两种非晴天气之间切换不会立即清零。累积的风动画时间避免风速变化导致波相跳变。关闭动态天气后同样平滑转晴。

体积雾默认开启，可在游戏设置切换「体积雾与阳光光束」。Forward+ 支持真实体积光；其它渲染器保留普通远景雾。晴天日光散射加强，夜间和雷暴降低。局部雾体跟随当前摄像机，边缘渐变；远景深度雾减轻，避免近景被重复灰雾遮住。

运行纹理：`assets/textures/environment_packs/`；模型：`assets/models/cartoon_plants/`。纹理及来源校验：`assets/source_packs/environment_20261011.json`；原算法与相关来源存档：`assets/source_packs/environment_shader_sources.zip`。导入工具在 `tools/assets/`，模型转换工具在 `tools/blender/environment_plants.py`。

喷泉池面提高到石台上方；小池设置最低着色深度 0.5 米，避免实体池底紧贴水面时整池变成白色相交泡沫。仍使用同一水面 Shader 和购买纹理。

验收图片与测量放在 `.shots/environment_20261011/`；可运行 `tests/environment_pack.tscn` 做同机位旧草/新草对照。`tests/environment_acceptance.tscn` 覆盖湖泊、体积光开关对照、镇区、海洋和返回前端；`tests/environment_motion.tscn` 补测最终喷泉、树冠上方昼夜天空及逐渲染帧动态，输出 `final_v3/`。动态 MP4 按真实采集时标编码，无插帧；采集每帧截图会影响采样帧率，不能以录像帧率当作正常游戏性能。测试角色不写入正式角色存档。

同机位旧草/新草采样：26,682 → 47,670 个实例，约增加 79%；0.761M → 2.037M 三角形，约增加 168%；帧时间中位数 11.11 → 16.785 毫秒，约增加 51%。这是本机固定视角的进程帧时间样本，不能代表精确 GPU 耗时或整个游戏帧率。增密采用远处减面网格和分块绘制，但并非无性能成本。

最终实际运行、独立复核及已知限制以 `PROJECT_STATE.md` 的本次追加记录为准。退出仍有既有纹理、字体、CanvasItem 与 ObjectDB 释放警告，不能声明整个工程零运行错误。

### 云风格、阴影与光照层次修订（2026-10-11）

用户随后明确要求「将云改回去，现在的云不正确」。当前 lighting-v4 已恢复本轮修改前的购买双层云纹理算法，包括原云形、明暗与覆盖；撤回圆团SDF和半分辨率云方案。云部分与本轮起始备份逐字一致，天气云量、累积风动画继续使用原接线。黄昏减少星点的修正保留。lighting-v2/v3 的圆团云截图只作为退役候选历史，不代表当前画面或用户认可。

太阳在6点升起、20点落下，白昼14小时、夜间10小时分段组成连续的24小时轨道。夕阳与月光平滑交接；月光也投影，白昼降低环境填光、加强方向受光和接触阴影。低角度夕阳提高阴影偏移，减少浅坡地面自阴影条纹。晴天前景体积雾略减，保留远景空气透视。

`local_light.gd` 为真实局部光提供跟随、火光波动和命中消退：法术弹体移动时照亮附近表面，命中光随特效清理；篝火、火盆使用非同步轻微波动，列车夜窗增加暖色补光。世界每0.25秒按玩家距离更新预算：最多14盏路灯、其中最近2盏可投影；最多8个效果光、其中最近1个可投影。所有投影服从游戏阴影开关，减少多人法术和镇区灯光叠加时的成本。

本批阴影开关和真实法术受体对照由 `tests/lighting_effects.tscn` 生成到 `.shots/lighting_20261011/lighting-v3-final/`，其中的灯光业务源码与当前一致，但云方案已撤回。测试包含预算饱和、设置开关、弹体/命中光清理和6/20/24点轨道接缝。`tests/lighting_rollback.tscn` 验证恢复云后的铁路/天空/镇区、水体、当前体积光开关及同窗口天空成本对照，输出 `lighting-v4-restored/`。具体结果与独立裁定在 `PROJECT_STATE.md` 追加记录；静态差分和数值轨道测试不能替代正常速度连续观看。投影和局部光有运行成本，本轮多进程/窗口状态下的帧时间有明显波动，不作为精确性能归因。
