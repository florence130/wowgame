## 8. Tripo 辅助清单（我这边的计划）

你发回设定图后，按这个顺序用 Tripo；**入库前一律把 4096² 贴图降到 ~1024，并按真实尺度缩放**（见记忆 `tripo-api-workflow`）。

| 优先级 | 物件 | 来源图 | 方式 | 备注 |
|---|---|---|---|---|
| ★★★ | 中央喷泉 | §5-1 | 图生 3D | 广场视觉中心，Blender 不好做雕花麦穗顶饰 |
| ★★★ | 传送石 | §5-2 | 图生 3D | 符文凹刻 + 发光水晶；发光件单独材质 `_emit` |
| ★★★ | 旅店 / 铁匠铺 / 治安所 外立面装饰（招牌架、徽章、屋脊饰） | §4-1/2/5 | 取部件 | 墙体屋顶仍由 Blender 做（已按真实尺度），Tripo 只出装饰件 |
| ★★ | 摊位 ×3、集市货物、手推车、干草堆 | §5-5–11 | 图生 3D | 小件 < 2k 面，可降面 |
| ★★ | 水井、路牌、公告板、稻草人 | §5-4/8/9/16 | 图生 3D | |
| ★ | 街灯、长椅、水槽 | §5 | Blender 已有，Tripo 作升级对比 | 先看设定图再决定 |
| ★ | 屋顶茅草 / 瓦面 | §6 | 贴图（不用 Tripo） | 直接做平涂贴图 |

规则：**每次文生固定出 4 个候选**（接口限制）；图生可指定数量。上传的参考图会在公网保留 30 分钟，我每次上传前会先告知。
