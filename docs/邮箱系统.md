# 邮箱

2026-10-08。系统信件：收信、领取附件、删除与过期。文案 `src/data/data_mail.gd`、逻辑 `src/core/mail.gd`、
界面 `src/ui/win_mail.gd`、世界邮箱柱 `src/world/postbox.gd`（摆放表在 `DataWorld.postboxes()`）。

## 入口

| 入口 | 说明 |
|---|---|
| 底栏「邮箱」按钮 | 有未读时按钮文字带数量并变金色（`hud.gd::_refresh_mail_badge`） |
| O 键 | 快捷键，可在设置里改（`Game.keybinds["mail"]`） |
| 世界里的邮箱柱 | 靠近后按交互键（默认 F）；共 7 座：晨露谷 3、潮风高地 3、风语旧圣堂 1 |

窗口左侧是收件列表（`●` 未读 / `✉` 有未领附件），右侧是正文与附件；
按钮有「领取附件 / 删除邮件」，左下角有「全部领取 / 清理已读」，底栏显示「共 N 封 · 未读 M」。

## 信件字段

`Game.pd["mail"]` 是数组（新信追加在末尾），`Game.pd["mail_seq"]` 是自增编号：

| 字段 | 含义 |
|---|---|
| id | 唯一编号，自增 |
| from / fid | 发件人显示名 / 可选阵营 id（信纸用该阵营关系配色） |
| subj / body | 主题与正文（正文可含换行） |
| items / money | 附件：`[{id, n}]` 与金币（单位为铜） |
| read / done | 是否已读 / 附件是否领完 |
| day | 收到时的游戏内天数（`Mail.now_day()`，1 天 = 24 游戏分钟） |

老存档在 `Game.load()` 里补 `mail` / `mail_seq` / `mail_boss` 三个键，**不升存档版本**。

## 规则

| 规则 | 行为 |
|---|---|
| 领取 | 物品走 `Game.add_item`；背包放不下时**留在信里**，金钱照付；`done` 只在清空后置 true |
| 一键领取 | `Mail.claim_all()` 依次领取所有带附件的信 |
| 删除 | 有未领附件时拒绝删除；「清理已读」只删已读且附件已领完的信 |
| 上限 | `MAX_MAIL = 40`：先挤掉「已读且领完」的旧信，仍超限则从最旧的开始丢 |
| 过期 | `EXPIRE_DAYS = 30`：已领完（无附件）且超过 30 天的信在载入时由 `Mail.prune()` 清理 |

## 系统钩子

| 事件 | 信件 | 接入点 |
|---|---|---|
| 升到 10/20/30/40/50/60 级 | 本职业训练师寄来祝贺信 + 补给（越往后越丰厚） | `Game._on_level_up()` → `Mail.on_level_up()` |
| 阵营关系升阶 | 该阵营军需官寄来祝贺信 + 补给（按 1–4 级给不同档） | `Rep.gain()` → `Mail.on_rep_tier()` |
| 副本首领首杀 | 对应势力寄来战报 + 赏金（每只首领只寄一次，记录在 `pd["mail_boss"]`） | `Game.on_kill()` → `Mail.on_boss_kill()` |

信件正文与附件都在 `DataMail` 的三个表里（`LEVEL_LETTERS` / `REP_LETTERS` + `REP_REWARDS` / `BOSS_LETTERS`），
改文案不用动逻辑。正文可以用 `%s` 点名收信人（`DataMail.rep_letter()` 会代入角色名；没有占位符时原样发送）。

## 验证（2026-10-08）

```powershell
$g = "F:\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64_console.exe"
& $g --headless --path E:\wowgame res://tests/mail.tscn -- core   # 纯逻辑
& $g --path E:\wowgame res://tests/mail.tscn                      # 含界面与世界邮箱柱
```

- `tests/mail.tscn`：**61 项全过**。数据完整性（信件附件都是真实物品、训练师是真实 NPC 且教对应职业、
  战报信一一对应副本首领、邮箱柱都落在真实区域）、投递/已读/领取/背包满时部分领取/删除规则/一键领取、
  过期清理与 40 封上限、三条系统钩子的真实链路（9 级 + 一级经验升到 10 级、声望跨到友善、首领首杀去重）、
  界面（列表行数、未读角标、领取按钮）、世界里走到邮箱柱前交互打开窗口。截图 `.local/mail_20261008/`。
- 本轮修掉两个真实缺陷：
  1. `DataMail.rep_letter()` 对正文里没有 `%s` 的阵营（晴岚港 / 冒险者公会 / 以太学者会 / 金穗镇）
     直接做字符串格式化会抛「not all arguments converted」，导致**升到友善时收不到信**；
     现在改为有占位符才代入，并把四个阵营的正文都补上称呼。
  2. `DataMail.level_letter()` 在 60 级时取 `LEVEL_LETTERS[6]` 越界；现在收敛到最后一档。

## 边界

- 只有系统寄信，没有玩家之间的寄信/包裹（单机）。
- 未做：附件有效期倒计时显示、邮件搜索、批量删除选择、收件箱分页。
- 邮箱柱只出现在三个区域，副本里的那一座是给「打完副本回城领赏」用的提醒。
