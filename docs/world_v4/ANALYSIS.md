## 0. “山谷下方是什么 / 平顶山为什么叫高地”

- 大世界只有两块野外地图：**东边晨露谷（1–10 级）**、**西边潮风高地（10–15 级，西岸就是晴岚港）**，两块南边都是海。风语旧圣堂是单独加载的副本。
- 代码和文档里**没有“南边还有一张高地地图”**的计划，也没有未完成的占位地图。最初路线图第 6 步就是“新手地图 1-10 + 沿海主城与外围 10-15 + 副本”，潮风高地就是“主城外围”那一块。
- 地图上那些平顶圆山是**生成器的写法造成的**，不是为某张缺失地图预留的：
  - `raise(圆心, 半径, 高度)` 堆一个圆锥，再 `flatten(圆心, 半径, 目标高度)` 把顶削平——狂牙岭 (200,800)、蔚蓝之塔 (620,780)、鸣风崖（高地 870,580）、灰巾帮哨营，都是这样做的。
  - 每个据点（哨站、农庄、站场、伐木场、葡萄园……）都用圆形 `flatten` 压一块平地，所以地图上到处是圆盘。
- “潮风高地”这个名字和地形对不上：它的地形只是基础高度 20m 加噪声的缓丘，比晨露谷（14m）只高几米，没有高原、没有断崖，**名不副实**。

## 1. 地形问题与根因

| 现象（用户反馈） | 根因（代码） |
|---|---|
| 矿坑是“圆形坡中间开了一个洞” | `gen_vale._terrain`：`raise(320,575,95,28)` 圆锥 + `modify` 半径 30–55 的圆形压到 9m，完全轴对称 |
| 多处“高地”是圆形平顶山 | `raise` + `flatten` 组合；`flatten` 是圆形、带 smoothstep 边缘，形成规整的台阶圆盘 |
| 镜湖像池塘 | `modify(760,300,120)`：半径 78m 的近圆形，湖底 2.5m，湖岸一圈均匀斜坡，没有湖湾、半岛、入湖溪流，周围也没有地形围合 |
| 山体结构不对 | 山全是低频 FBM 噪声的圆鼓包（`n2` 一层 + 北缘 `pow` 斜坡），没有山脊线、山谷、冲沟、岩壁；岩石只在坡度 >0.42 处换贴图，于是坡面出现大片灰色“条纹”（见修道院后山） |
| 过渡突兀 | 各种 `flatten` / `flatten_rect`（修道院高台削出直角岩壁）直接覆盖地形；接缝过渡带 110m 也是统一插值 |
| 草叶太细、地面突兀 | `grass_field.gd` 草叶半宽 1.8–3.2cm、高 0.26–0.55m、间距 0.55m：叶片细、缝隙里露出大片地表，地表贴图与草叶颜色差大 |

## 2. 晴岚港现状 vs 参考图

**现状**（`gen_solenne.gd` v3）：城区约 620 × 640m；约 245 栋联排住宅**逐栋**沿街摆放，房子之间是草坪，没有连续街区；街道近似规则网格；地形基本平坦（三层台地）；城墙是简单多边形；城外直接是空旷草地。

**图四（平面）要点**：
- 城市环抱南面一个**大圆海湾**；一条**河从东蜿蜒穿城**，在城中注入**内港水池**（有桥），再通海湾。
- 分区明显：河北、河南、湾东三大片，每片有**放射状大街 + 圆形广场（喷泉）**，次级街道沿弧线展开。
- 街区是**连续的周边式街坊**（房子沿街连成一圈，中间是内院），屋顶连成片。
- 西端海岬：**宫殿 / 要塞区**（规则园林、红顶楼阁、圆形塔楼）。
- 城墙沿陆地边缘，带棱堡；城外是**成块的农田、散落农庄、林地**，海岸是礁石崖。
- 尺度：参考图的街坊数量约是现在的 4–6 倍。

**图三（鸟瞰）要点**：
- **半岛山城**：城市建在临海高地上，中央有**山丘、绿地、圆塔和穹顶教堂**，城内有地形高差和岩坡。
- **港口**：防波堤尽头的**灯塔堡**，港内泊船，码头前是带红色遮阳篷的市场街。
- 西侧海岬上有**修道院式要塞**；城墙连续，**圆形塔楼**间隔排布，陆侧城门出大路。
- 城墙外西南是**下城区**（棕顶、灰顶小屋，密集无序，沿坡下到海边）。
- 屋顶配色：**紫 / 薰衣草、蓝、灰蓝、少量棕红**；墙面奶白。
- 城外：篱笆分隔的田块（bocage）、葡萄园条垄、成片森林。

**两图的共同点（就是现在缺的）**：连续街坊肌理、有机而分级的路网（主街—广场—次街—小巷）、城墙 + 塔楼、真实的海岸与港口、地形高差、城外农田与下城区、规模更大。

## 3. 改造方向（待用户确认后执行）

### 3.1 地形（两块野外地图）
1. **地貌骨架改成“分区 + 脊线”**：用脊状噪声 + 方向性山脉，做出北部群山的山脊、山谷、冲沟；高地做成真正的高原（见决策 Q1）。
2. **废弃圆形 raise/flatten**：据点平地改为“沿等高线的不规则平台”（噪声扰动边界、按坡向逐渐融入），高地据点放在自然台地 / 山肩上。
3. **矿坑**：改成开在山体侧面的**阶梯式露天采场**（不规则形状、台阶 + 坡道 + 废石堆），而不是圆锥开洞。
4. **镜湖**：扩大成**有湖湾、半岛、入湖溪流和出湖河**的山间湖，三面山坡围合、一侧滩地。
5. **岩石**：陡坡换成手绘风岩壁贴图（按坡度分层：草 → 土石 → 岩），加岩石露头模型；修道院后山改为自然坡 + 挡土石墙。
6. **草**：叶片加宽到 5–8cm、单丛叶数增加、间距收紧，草根色和地表色对齐，消除“细草 + 秃地”。

### 3.2 晴岚港 v4

布局草案（待用户确认）：`city_plan.json` → `city_plan.png`（`py tools/draw_city_plan.py`）。
- 城区约 1.2 × 1.0km，地形需向西扩展：潮风高地地形原点 (-320,-160) → 约 (-1040,-160)，边长 1280 → 约 2000m（世界偏移不变，晨露谷接缝不受影响）。
- 性能：约 1500–2000 栋连续街坊住宅不能再一栋一个节点（现在 245 栋已是逐栋 ModelProp）。改为按街坊批量：同款模型 MultiMesh 合批，墙色 / 屋顶色走实例颜色，碰撞用每栋一个盒子，远景 LOD。
- 程序化**街坊生成**：先定主路网（城门—广场—港口—桥），再沿等高线 / 河岸生成次街，切出街坊多边形，沿街坊边连续排房（共享山墙）、内院留空，屋顶合批（MultiMesh / 合并网格 + 远景 LOD）。
- 保留现有全部 NPC、服务、POI、出生点 id（只换坐标）。
