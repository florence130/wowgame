## 🔄 阶段2：战士职业重构（准备开始）

### 设计目标
**核心机制**：势能（Momentum）系统
- 0-100点势能，影响移动速度和技能效果
- 蓄力技能积累势能
- 爆发技能消耗势能

### 技能设计框架（参考设计方案）
| 类型 | 数量 | 说明 |
|------|-----|------|
| 蓄力技能 | 2 | 产生势能，短CD |
| 连招技能 | 6 | 3链×2路径，中等势能消耗 |
| 爆发技能 | 3 | 高势能消耗，高伤害 |
| 工具技能 | 2 | 冲锋、嘲讽等 |
| 被动/特性 | 待定 | 15级转职后解锁 |

## 🎯 设计原则调整

根据用户反馈，已调整以下设计：

### ✅ 已采纳
1. **移除天赋系统** → 改为15级转职 + 主动/被动/特性技能
2. **接受复杂度** → 每职业独特资源系统
3. **不保留旧版** → 允许破坏存档，全面重构

3. **特性技能** - 改变技能机制的天赋式被动
