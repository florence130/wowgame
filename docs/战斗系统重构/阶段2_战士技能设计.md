# 阶段2：战士职业技能设计

**职业**: 战士（Warrior）  
**核心资源**: 势能（Momentum）0-100点  
**次要资源**: 怒气（Rage）0-100点  
**特色机制**: 蓄力→爆发，势能越高移动速度越快

---

## 💡 核心循环

1. **蓄力阶段**（0-60势能）：使用蓄力技能积累势能
2. **连招阶段**（30-80势能）：释放连招链消耗中等势能
3. **爆发阶段**（60-100势能）：释放大招消耗高势能
4. **循环重置**：势能耗尽，重新蓄力

**移动速度加成**：基础速度 × (1 + 势能/200)  
- 0势能：100%速度
- 50势能：125%速度
- 100势能：150%速度

## 📋 技能列表（15个）

### 🔹 基础技能（2个）

#### 1. 自动攻击（attack）
- **类型**: 被动切换
- **效果**: 近战普攻，产生5点怒气/次
- **说明**: 继承原有自动攻击

#### 2. 翻滚闪避（dodge_roll）
- **类型**: 通用闪避
- **效果**: 0.8秒无敌，消耗30耐力
- **CD**: 2秒
- **说明**: 所有职业通用

---

### ⚡ 蓄力技能（2个）- 产生势能

#### 3. 蓄势待发（gather_momentum）
- **施法**: 1.5秒引导
- **CD**: 3秒
- **效果**: 
  - 引导期间每0.5秒产生15势能（共45势能）
  - 可移动施法，但移动速度-30%
  - 被打断损失已积累势能
- **特性**: 战斗起手技能

#### 4. 战吼激励（battle_shout）
- **施法**: 瞬发
- **CD**: 20秒
- **效果**:
  - 立即获得30势能
  - 10秒内攻击力+15%
- **特性**: 快速进入连招节奏

## 🎮 典型战斗循环

### 单体输出循环
```
1. 战吼激励（获得30势能+攻击增益）
2. 斩击（45势能，启动连招链）
3. 重劈（25势能，连招第2段）
4. 终结斩（0势能，连招终结）
5. 蓄势待发（45势能，重新蓄力）
6. 破甲重击（-5势能，消耗怒气爆发）
7. 重复连招...
```

### AOE输出循环
```
1. 战吼激励（获得30势能）
2. 旋风斩（10势能，AOE连招起手）
3. 雷霆一击（-15势能，击退+AOE）
4. 蓄势待发（30势能）
5. 大地震击（0势能，眩晕+高伤）
6. 重复...
```

### 爆发循环
```
1. 蓄势待发（45势能）
2. 战吼激励（75势能）
3. 狂暴之怒（-5势能，超高伤+暴击）
4. 致死打击（-65势能，重伤效果）
5. 连招收尾...
```

## 📊 数值平衡

### 势能经济
- **总池**: 100点
- **主要来源**: 蓄势待发45点/1.5秒，战吼激励30点/20秒CD
- **主要消耗**: 连招链60-80点，爆发50-80点
- **循环时长**: 约15-20秒完整循环

### 怒气经济
- **总池**: 100点
- **主要来源**: 自动攻击5点/次，连招10-20点
- **主要消耗**: 爆发技能30-50点
- **作用**: 限制爆发技能频率

### DPS预估（等级10，基础装备）
- **持续DPS**: 约150-200/秒
- **爆发DPS**: 约400-500/秒（狂暴之怒期间）

---

## 🎯 设计特色

1. **蓄力手感**: 需要规划蓄力时机，不能无脑连招
2. **移动加速**: 高势能时跑得更快，符合"势能"主题
3. **双路径**: 单体/AOE两条连招链，适应不同场景
4. **风险收益**: 狂暴之怒高伤但增加受伤，需要判断时机
5. **打断惩罚**: 蓄势待发被打断损失进度，需要走位
