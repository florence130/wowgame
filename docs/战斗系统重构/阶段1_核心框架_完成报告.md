## 📋 已实现的功能

### 1. 连招链系统 ✅
**位置**: `src/actors/unit.gd`

- **技能定义**：支持 `combo_chain_set` 字段设置连招标记
- **校验逻辑**：`check_cast` 中验证 `requires.combo_chain`
- **状态管理**：
  - `combo_chain: String` - 当前连招标记
  - `combo_window: float` - 连招窗口时间（默认4秒）
  - 战斗中自动衰减

**示例**:
```gdscript
# 技能A设置连招链
{
  "combo_chain_set": "slash_2",
  "combo_window": 4.0
}

# 技能B需要连招链
{
  "requires": {"combo_chain": "slash_2"}
}
```

### 2. 耐力系统 ✅
**位置**: `src/actors/unit.gd`

- **资源池**: 100点耐力，所有职业通用
- **消耗机制**: 闪避消耗30点，连续闪避递增（+10）
- **恢复速度**: 战斗中 10/秒，非战斗 20/秒
- **状态字段**:
  - `stamina: float = 100.0`
  - `max_stamina: float = 100.0`
  - `stamina_regen_rate: float = 10.0`
  - `dodge_cost: float = 30.0`

### 3. 无敌帧机制 ✅
**位置**: `src/actors/unit.gd`

- **效果类型**: `"dodge"` - 0.8秒免疫所有伤害
- **实现逻辑**:
  - `apply_effects` 中添加 `dodge` 类型处理
  - 设置 `invincible` 标记
  - 定时器恢复
- **技能数据**: 通用闪避技能 `dodge_roll` 已添加

**通用闪避技能定义**:
```gdscript
"dodge_roll": {
  "id": "dodge_roll",
  "name": "翻滚",
  "rank": 1,
  "cast": 0.0,
  "cd": 2.0,
  "target": "none",
  "school": "physical",
  "cost": {"stamina": 30},
  "effects": [{"type": "dodge", "duration": 0.8}],
  "desc": "向前翻滚，0.8秒内免疫所有伤害。消耗30点耐力，冷却2秒。"
}
```

### 4. 方向输入系统 ✅
**位置**: `src/actors/unit.gd` + `src/actors/player.gd`

- **输入检测**: `get_move_direction()` - 返回 `"forward"/"backward"/"left"/"right"/"none"`
- **技能分支**: 支持 `directional: true` 的技能根据方向切换效果
- **效果覆盖**: 方向键（`forward`/`backward`/`left`/`right`）覆盖主 `effects` 数组

**方向技能示例**:
```gdscript
{
  "directional": true,
  "forward": [{"type": "damage", "min": 50, "max": 70}],
  "backward": [{"type": "dash", "distance": -5}],
  "left": [{"type": "damage", "min": 30, "max": 40, "aoe": true}],
  "right": [{"type": "damage", "min": 30, "max": 40, "aoe": true}]
}
```

### 5. 专精资源框架 ✅
**位置**: `src/actors/unit.gd` + `src/actors/player.gd`

**Unit字段**:
```gdscript
var spec_resource: float = 0.0          # 通用专精资源
var max_spec_resource: float = 100.0
var spec_resource_type: String = ""     # 类型标识
var spec_resource_alt: float = 0.0      # 双值系统的第二资源
var fire_charges: int = 0               # 法师火充能
var frost_charges: int = 0              # 法师冰充能
```

**职业初始化**（在 `player.gd:load_from_data`）:
| 职业 | 资源类型 | 最大值 | 说明 |
|------|---------|--------|------|
| 战士 | `momentum` | 100 | 势能 |
| 法师 | `fire_charges` + `frost_charges` | 3+3 | 火冰充能 |
| 牧师 | `holy_shadow` | 100+100 | 圣暗双值 |
| 盗贼 | `shadow_marks` | 5 | 影刃标记 |
| 枪手 | `heat` | 100 | 过热 |
