# 天赋系统

2026-10-08。给 5 个职业各加两条专精路线。数据 `src/data/data_talents.gd`、逻辑 `src/core/talents.gd`、
界面 `src/ui/talent_panel.gd`（作为技能书窗口的第二个页签嵌入，见 `src/ui/win_spells.gd`）。
入口：**N** 打开「技能与天赋」窗口的天赋页签（P 打开技能页签）。

> 同批的界面调整：**背包已并入角色窗口**（`win_char.gd` 里以 `BagWindow.new(true)` 嵌入式面板呈现，
> `hud.gd` 的 `WIN_ALIAS` 让 `bag` / `talents` 这两个旧窗口 id 仍然可用）。

## 规则

- **点数**：10 级起每级 1 点，满级 20 共 **11 点**。未满 10 级的角色点数为 0。
- **结构**：每职业 **2 系**；每系 **4 层**，层级分布 **2/2/2/1**（共 7 个天赋）。天赋等级上限 1–3。
- **层数门槛**（本系已投入点数）：第一层 0、第二层 2、第三层 4、终章 6。
- **投点**：左键 +1，右键 -1。退回时若会让同系更高层天赋的门槛失效，则被拒绝（提示先退高层）。
- **洗点**：只能在本职业训练师（或通用导师「奥斯卡」）处重置，费用 **每点 5 银**；重置后点数全部返还、
  终章技能一并收回。训练师对话页里同时提供「打开天赋面板」入口。
- 一条天赋的效果随等级线性叠加，界面文案由 `Talents.effect_lines()` 由数值自动生成，不在文本里写死数字。

## 两条路线与终章技能

| 职业 | 第一系（终章） | 第二系（终章） |
|---|---|---|
| 战士 | 武器 — 致死打击 | 防护 — 盾墙 |
| 法师 | 火焰 — 炎爆术 | 冰霜 — 寒冰护体 |
| 牧师 | 神圣 — 强效治疗术 | 暗影 — 暗影形态 |
| 盗贼 | 刺杀 — 冷血 | 战斗 — 剑刃乱舞 |
| 魔导枪手 | 射击 — 瞄准射击 | 生存 — 魔导过载 |

终章天赋授予的是真正的主动技能：学习后进入技能书并自动放到空的动作条格；退回或洗点时从技能书与动作条一起清除。
这些技能不由训练师出售（`DB.classes[cls]["spells"]` 里没有它们，只有天赋能给出）。

## 效果乘区

| 效果键 | 含义 | 生效位置 |
|---|---|---|
| `stats` / `stats_pct` | 固定 / 百分比属性（力量、耐力、护甲、暴击、闪躲…） | `Player.recalc_stats()`（`ap`/`rap` 在推导之后乘） |
| `school_dmg` | 按学派的伤害加成（含 `"*"` 通用） | 近战、法术、远程与持续伤害各自的乘区 |
| `dot_pct` | 持续伤害加成 | `Unit._aura_tick()`（施法方结算） |
| `heal_pct` | 治疗加成 | `Unit.receive_heal()` |
| `cost_pct` | 消耗降低（技能 id / 学派 / `"*"`） | `Unit.spell_cost()` |
| `cd_pct` | 冷却缩短（技能 id / `"*"`） | `Unit._start_cd()` |
| `cast_pct` | 施法速度 | `Unit.cast_time()` |
| `dur_pct` | 你施加的增益与减益持续时间 | `Unit._scaled_dur()`（只改这一次实例，不动共享定义） |
| `dmg_taken` | 受到的伤害降低 | `Unit.take_damage()` |
| `threat` | 造成的威胁值 | `Unit.add_threat()`（按攻击方） |
| `speed` / `haste` | 移动速度 / 攻击速度 | `move_speed()` / `attack_haste()` |
| `ranged_dmg` | 远程武器伤害 | `deal_spell_damage(ranged_phys)` |
| `hp_pct` / `regen` | 生命上限 / 生命与法力回复 | `recalc_stats()` / `_tick_regen()` |
| `grant` | 终章技能 id | `Talents.sync_spells()` |

天赋加成只作用于玩家：`Unit.talent_mods` 由 `Player.recalc_stats()` 写入，怪物与 NPC 保持空字典，
`Unit.tmod()` 系列在空字典时直接返回 0 / 1.0，因此没有天赋的单位不承担任何额外开销。

## 存档

`pd["talents"] = {talent_id: rank}`。老存档缺这个键时在载入与首次访问时自动补齐，不升存档版本。
载入时会 `Talents.sync_spells()` 重新对齐终章技能，因此洗点后即使旧存档里残留技能也会被收回。

## 边界

- 本轮不引入天赋专属资源（无天赋点购买、无天赋装备）。
- 天赋不影响副本/传送/世界分块逻辑；跨区域、进副本、洗点都会重新结算属性。
- 未做：天赋预设/双天赋切换、天赋与 PvP 平衡（游戏暂无 PvP）、按学派的抗性。
- 界面合并的取舍：**按钮栏仍保留「角色 / 背包 / 技能 / 天赋」四个入口**（前两个打开同一个角色页，
  后两个打开同一个技能与天赋窗口的不同页签），键位 C / B / P / N 全部保留；旧窗口 id `bag` / `talents`
  继续可用（`hud.gd` 的 `WIN_ALIAS`），因此脚本与测试里按旧 id 打开窗口依然有效。
