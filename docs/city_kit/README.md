# 晴岚港城市建筑构件库 city_kit v1

用来快速搭建重复的建筑立面、造型和屋顶。拆分依据：

- 两段参考视频：`E:\DOWNLOADS\41418490820-1-192.mp4`、`E:\DOWNLOADS\41403485769-1-192.mp4`（抽帧见 `docs/city_ref/sheet_*.jpg`）。
- 2026-10-09 的 5 张参考图：车站港区、千泉城商业街（青铜屋顶）、黄昏圆形广场、第二帝国式市政厅、夜景宫殿园林。
  已存为 `docs/city_ref/ref15…ref19`。

视频里反复出现的立面语汇，被拆成下面的构件：

- 底层横缝石墙面，开拱窗、拱门、过街拱或商铺橱窗。商铺带墨绿店招和红白条纹雨篷。
- 标准层用红砖、灰泥或方石墙面。高窗配石窗套，窗楣有檐板、三角山花或弧形山花，另有法式落地窗配弓形铁艺阳台。
- 层间腰线；牛腿加齿饰的主檐口；女儿墙栏杆；转角隅石；壁柱。
- 芒萨尔屋顶，带三角山花或圆窗老虎窗。另有帝国式钟形亭顶、穹顶带采光亭、圆角楼加尖顶，以及钟楼钟层。
- 双柱门廊、大山花、凯旋式拱门、铁艺屋脊花饰、烟囱、壁灯、花箱。

## 模数与坐标

| 项 | 值 |
|---|---|
| 开间 | 4.4 m（每块立面构件宽度） |
| 底层层高 | 5.6 m |
| 标准层层高 | 4.4 m |
| 墙厚 | 0.3 m（与 `tools/blender/modkit` 一致，可混用 modkit 的门窗） |
| 芒萨尔 | 高 4.4 m；底边外出墙中心线 0.5 m，顶边内收 1.1 m |

- **坐标**：游戏内（glTF / Godot）构件沿 +X 展开 0..4.4，外立面朝 +Z，Y 向上，原点在左下角墙中心线。
- **例外**：塔身、尖顶、穹顶、亭顶、钟层的原点在底面中心。芒萨尔转角件的原点在建筑外角。
- **拼法**：
  - 底层放在 y=0，标准层在 y = 5.6 + 4.4·k，腰线在每层楼板线下 0.16 m。
  - 檐口放在墙顶下 0.86 m，芒萨尔放在墙顶。
  - 隅石放在四个外角，每层一段。
- **材质**：材质名为 `K|类型|颜色|细节贴图|米`，游戏端由 `U.kit_mat` 换成 `building.gdshader`。
  `*_nocol` 子网格（玻璃、植物、发光）不生成碰撞。

## 建模手法

全部构件只用 modkit 规定的十种手法，并登记在每个对象的 `methods` 属性里，`manifest.json` 里也有。十种手法都已用到：

镜像、阵列、截面挤出、实体化、曲线倒角、旋绕、曲线变形（弓形阳台）、桥接（墙板开洞）、简单形变（烟囱收分）、几何顶点（隅石、花草错位）。

## 文件

- 构件定义：`tools/blender/city_kit/city_kit.py`
- 构建脚本：`tools/blender/city_kit/build.py`
- 产物：
  - `assets/models/city_kit/<id>.glb`
  - `assets/models/city_kit/manifest.json`（尺寸、包围盒、三角面数、手法）
  - 缩略图 `docs/city_kit/<id>.png`（带 1.75 m 红色人形比例尺）
- 游戏端：
  - `src/world/city_kit.gd`：`CityKit.piece(id, xf)` 放单件，`CityKit.building(spec)` 用一份规格生成整栋楼。
  - `tests/city_kit_gallery.tscn`：陈列全部构件、示范建筑和一栋运行时拼装楼，截图在 `.shots/city_kit/`。

构建命令：

```bash
"E:\FF导出\BlenderPortable\blender-4.5.10-windows-x64\blender.exe" -b -P tools/blender/city_kit/build.py -- all
```

参数可以是 `all`、`pieces`、`demos`，或者逗号分隔的构件 id。

## 运行时拼装示例

```gdscript
var b := CityKit.building({"nx": 4, "nz": 3, "floors": 3, "gf": "SADS", "uf": ["balc", "pedi", "seg"],
	"wall": "stucco", "roof": "slate", "dormer": "oculus", "turret": true})
add_child(b)   # 占地 x∈[0, 17.6]、z∈[-13.2, 0]，正面朝 +Z；这一栋由 143 个构件组成
```

`gf` 是底层编码，按 front → right → back → left 逐开间循环取用：

| 编码 | 构件 |
|---|---|
| `A` | 拱窗 |
| `D` | 拱门 |
| `O` | 过街拱 |
| `S` | 商铺（带雨篷） |
| `s` | 商铺（无雨篷） |
| `W` | 实墙 |

`uf` 是各层窗式，可选 `plain`、`pedi`、`seg`、`balc`、`solid`。`wall` 可选 `brick`、`stucco`、`ashlar`；`roof` 可选 `slate`、`copper`、`flat`。

## 已知限制

- **还没进城**：晴岚港的程序化沿街楼（`tools/city_plan_v6`）还没换成构件拼装。下一步可以按 `LOTS` 的临街面宽，取整成开间后用 `CityKit` 生成。
  拼装后的单栋约 8–10 万三角面，进城时需要合批：同一构件用 MultiMesh，或者每个街坊合并成一块。
- **芒萨尔转角件**：直段要从转角内收 1.1 m 处起拼；示范建筑的转角用的是圆角楼。
- **铜质屋面高光**：在陈列场景的纯色环境里，铜质屋面会出现镜面高光白斑。在城市实景里还没验证过。
