## 一、FF14副本核心特征分析

### 1.1 结构特点
```
线性推进 + 3-4个Boss房间
├─ 入口区（Tutorial/Warmup）
├─ 小怪区1 → Boss房1（第一守门人）
├─ 小怪区2 → Boss房2（中间Boss）
├─ 小怪区3 → Boss房3（最终Boss）
└─ 出口/宝箱区
```

**关键设计原则**：
- ✅ **风格统一**：从入口到终点，同一主题贯穿始终
- ✅ **视觉识别**：每个区域有标志性场景元素（但不打破主题）
- ✅ **节奏控制**：小怪区 → Boss房 交替，战斗与探索平衡
- ✅ **空间叙事**：场景讲述故事（从外围 → 核心圣所）

### 1.2 房间类型标准化

| 类型 | 尺寸 | 特征 | 装饰密度 |
|------|------|------|----------|
| **入口区** | 15×15m | 安全区，传送门，标牌 | 低（引导性） |
| **小怪走廊** | 30×10m | 线性，2-3波小怪 | 中（柱子/断壁） |
| **Boss圆形竞技场** | 25m直径 | 圆形/八角形，中央区域 | 高（主题元素） |
| **宝箱/休息区** | 12×12m | 方形，单个宝箱 | 低（功能性） |

## 二、潮汐圣所主题统一设计

### 2.1 核心主题
**海神遗弃的希腊式神殿废墟**
- 建筑：纯白大理石 + 多立克柱式
- 装饰：爱琴海蓝旗帜 + 海洋图腾（波浪/海豚/贝壳浮雕）
- 破损：断裂的柱子 + 青苔 + 野草
- 光照：地中海明亮阳光（入口） → 幽暗神殿（深处）

### 2.2 故事线（空间叙事）
```
外围台阶（入口）
    ↓ 玩家从高处俯视整个废墟
柱廊广场（小怪区1）— 露天，5根立柱，断壁
    ↓ 
前厅守卫Boss房（碎帆·拉克）— 圆形，水池中央
    ↓
祈航殿走廊（小怪区2）— 室内，蓝色旗帜悬挂
    ↓
缠殿者Boss房（圆形祭坛）— 八角形，中央祭坛
    ↓
钟塔阶梯（小怪区3）— 螺旋上升，破损台阶
    ↓
旧出航钟台（最终Boss）— 圆形，顶层露天平台
```

## 四、白盒制作规范

### 4.1 Blender工作流
```
1. 使用已有的基础构件（doric_column_complete.glb等）
2. 每个房间单独场景文件（sanctum_room_XX.blend）
3. 构件实例化（不复制几何体）
4. 统一原点：地面Y=0，房间中心X/Z=0
5. 导出：每房间一个GLB（colliders ON）
```

### 4.2 Godot集成
```gdscript
# gen_sanctum.gd 重构
const ROOMS = {
    "entrance": preload("res://models/sanctum/rooms/entrance.glb"),
    "plaza": preload("res://models/sanctum/rooms/plaza.glb"),
    "boss_1": preload("res://models/sanctum/rooms/boss_lake.glb"),
    # ...
}

func build_room(room_id: String, position: Vector3):
    var room = ROOMS[room_id].instantiate()
    room.position = position
    return room
```

### 4.3 测试Checklist
- [ ] 玩家能从入口走到终点

- [ ] 小怪区有明确的推进路线
- [ ] 碰撞正常（不卡墙，不穿模）
