# 战斗系统改造总结

## 改造日期
2026-10-12

## 改造目标
将战斗系统从纯站桩攻击改造为半动作系MMORPG风格，增加：
- 主要循环和连招机制
- 职业独特资源系统
- 位置判定（背后/侧面）
- 闪避与耐力系统
- 重新设计的技能和天赋树

## 核心系统变更

### 1. 新增资源系统
所有职业改为**0消耗技能**，使用独特资源系统：

| 职业 | 资源类型 | 机制 |
|------|---------|------|
| 战士 | 势能(Momentum) | 攻击积累，消耗爆发；闲置衰减 |
| 法师 | 充能(Charges) | 火焰/冰霜双充能，混合消耗 |
| 盗贼 | 能量+连击点 | 能量恢复，连击点终结 |
| 牧师 | 双标记系统 | 圣光/暗影标记，堆叠消耗 |

### 2. 闪避与耐力系统
- 新增 `stamina` / `max_stamina` 属性（基础100点）
- 闪避消耗30耐力，连续闪避递增消耗（+20/次）
- 不闪避时自动恢复（25点/秒）
- 耐力不足时无法闪避

### 3. 位置判定系统
- `is_behind(target)` - 判断是否在目标背后（120度扇形）
- `is_flanking(target)` - 判断是否在侧面（侧面90度扇形）
- 盗贼技能依赖位置产生额外效果

### 4. 连招链系统
- 技能可设置 `combo_chain` 标记
- 后续技能可要求特定 `combo_chain` 才能释放
- 连招窗口4秒，超时清空

## 职业技能重设计

### 战士 (Warrior) - 势能系统
**核心循环**: 普攻/重击积累势能 → 旋风斩/狂暴打击消耗

| 技能 | 类型 | 效果 |
|------|------|------|
| 冲锋 | 起手 | 冲向目标，产生30势能 |
| 雷霆一击 | 生成 | 武器伤害+30势能，设置连招链 |
| 顺劈斩 | 生成 | 需要连招链，武器伤害+30势能 |
| 横扫攻击 | 生成 | 180度扇形AOE，武器伤害+40势能 |
| 旋风斩 | 消耗 | 需要60势能，消耗所有势能，每10点造成60伤害 |
| 狂暴打击 | 爆发 | 需要80势能，消耗所有势能，每10点造成80伤害+自身加速 |
| 致死打击 | 斩杀 | 需要50势能，对低血目标额外伤害 |
| 破甲攻击 | 削弱 | 需要40势能，降低护甲30% |
| 挫志怒吼 | 控制 | 8码AOE恐惧 |
| 战斗怒吼 | Buff | 攻强+50持续30秒 |

### 法师 (Mage) - 充能系统
**核心循环**: 火球/寒冰箭生成充能 → 炎爆术/奥术冲击消耗

| 技能 | 类型 | 效果 |
|------|------|------|
| 火球术 | 火焰生成 | 2秒施法，伤害+1火焰充能+火焰爆发状态 |
| 烈焰风暴 | 火焰AOE | 需要火焰爆发，引导3秒，8码AOE持续伤害 |
| 炎爆术 | 火焰爆发 | 需≥3火焰充能，瞬发，高伤害+DOT，消耗所有火焰充能 |
| 寒冰箭 | 冰霜生成 | 2秒施法，伤害+1冰霜充能 |
| 冰枪术 | 冰霜爆发 | 需≥3冰霜充能，瞬发，高伤害+70%减速，消耗所有冰霜充能 |
| 暴风雪 | 冰霜AOE | 引导3秒，8码AOE减速+伤害 |
| 奥术冲击 | 混合消耗 | 需≥3充能（任意），消耗所有，每层+50伤害 |
| 奥术飞弹 | 爆发期 | 需奥术爆发状态，引导3秒，3发共720伤害 |
| 闪现术 | 机动 | 瞬移20码+解控 |
| 寒冰护体 | 防御 | 吸收800伤害护盾 |

### 盗贼 (Rogue) - 能量+连击点
**核心循环**: 毒刃/割裂生成连击点 → 剔骨/切割消耗

| 技能 | 类型 | 效果 |
|------|------|------|
| 毒刃 | 生成 | 武器伤害+1连击点+中毒DOT（可叠3层） |
| 暗影突袭 | 爆发生成 | 瞬移背后+武器伤害+2连击点 |
| 割裂 | 双持生成 | 双武器攻击+2连击点（背后3点） |
| 剔骨 | 终结技 | 消耗连击点造成伤害+返还能量 |
| 切割 | 终结技 | 消耗连击点+出血DOT |
| 肾击 | 终结技 | 消耗连击点+昏迷 |
| 消失 | 机动 | 进入潜行+脱战 |
| 疾跑 | 机动 | 移速+70%持续8秒 |
| 闪避 | 防御 | 100%闪避持续5秒 |

### 牧师 (Priest) - 双标记系统
**核心循环**: 
- 圣光路线：惩击/神圣之火堆圣光标记 → 苦修爆发
- 暗影路线：暗言术痛/心灵震爆堆暗影标记 → 暗言术灭斩杀

| 技能 | 类型 | 效果 |
|------|------|------|
| 惩击 | 圣光生成 | 神圣伤害+1圣光标记 |
| 神圣之火 | 圣光快速生成 | 神圣伤害+DOT+2圣光标记 |
| 苦修 | 圣光消耗 | 需≥3圣光标记，引导3发，每发伤害+每层标记加成 |
| 暗言术：痛 | 暗影生成 | DOT+1暗影标记 |
| 心灵震爆 | 暗影快速生成 | 暗影伤害+2暗影标记 |
| 精神鞭笞 | 暗影增强 | 引导伤害，每层暗影标记+30伤害+减速 |
| 暗言术：灭 | 暗影斩杀 | 需≥3暗影标记，高伤害+斩杀加成，消耗所有标记 |
| 快速治疗 | 治疗 | 治疗+圣光标记加成 |
| 恢复 | HOT | 15秒HOT |
| 真言术：盾 | 防御 | 吸收护盾+虚弱灵魂debuff |
| 心灵尖啸 | 控制 | 8码AOE恐惧 |

## 新增Effect类型

### 资源生成
- `{"type": "gain_momentum", "amount": 30}` - 获得势能
- `{"type": "add_charge", "charge_type": "fire"}` - 添加充能
- `{"type": "combo", "n": 1, "n_from_behind": 2}` - 产生连击点
- `{"type": "add_mark", "mark_type": "holy", "amount": 1}` - 添加标记

### 资源消耗
- `{"type": "consume_momentum"}` - 消耗势能
- `{"type": "consume_all_charges"}` - 消耗所有充能
- `{"type": "finisher_damage", "per_cp": [...]}` - 终结技伤害
- `{"type": "consume_marks", "mark_type": "shadow"}` - 消耗标记

### 增强效果
- `damage` effect 支持 `per_momentum` / `per_charge` / `per_holy_mark` 等加成
- `damage` effect 支持 `execute_bonus_threshold` / `execute_multiplier` 斩杀加成

### 位置相关
- `{"type": "teleport_behind"}` - 瞬移到目标背后

### 连招链
- `{"type": "set_combo_chain", "chain": "thunder_strike"}` - 设置连招链

## 新增Requires类型

### 资源要求
- `{"combo": true}` - 需要至少1连击点
- `{"spec_resource_min": 60}` - 需要最少势能
- `{"fire_charges_min": 3}` - 需要最少火焰充能
- `{"min_charges": 3}` - 需要最少总充能
- `{"holy_marks_min": 3}` - 需要最少圣光标记
- `{"shadow_marks_min": 3}` - 需要最少暗影标记

### 状态要求
- `{"has_aura_self": "fire_surge"}` - 需要自身有特定光环
- `{"combo_chain": "thunder_strike"}` - 需要特定连招链
- `{"stealth_or_behind": true}` - 需要潜行或在背后
- `{"dual_wield": true}` - 需要双持（暂未实现）

### 其他要求
- `{"stamina_min": 30}` - 需要最少耐力（闪避累计递增）

## 兼容性说明

### 已破坏的兼容性
1. **所有技能定义已替换** - 旧的21个技能已被新的40+技能替代

### 保留的兼容性
1. **基础战斗逻辑** - `cast_spell()` / `take_damage()` 等核心函数未变
2. **光环系统** - Aura/DOT/Buff/Debuff机制保持不变
3. **目标系统** - 目标选择和范围检测逻辑不变

## 设计理念

本次改造遵循以下设计原则：

1. **节奏感** - 通过资源生成/消耗循环创造决策点
2. **差异化** - 每个职业有独特的玩法手感
3. **深度** - 位置判定/连招链增加技术天花板
4. **反馈** - 闪避/耐力/标记等系统提供即时反馈
5. **可扩展** - 天赋树和专精系统预留扩展空间
