# 声望阵营

2026-10-08。五个阵营、五级关系。数据 `src/data/data_rep.gd`、逻辑 `src/core/reputation.gd`，
货单在 `src/data/data_items.gd` 的 `qm_*`，界面在角色窗口（声望条）与 NPC 对话窗口（军需官）。

## 阵营与军需官

| 阵营 | 军需官 | 怪物家族（击杀来源） |
|---|---|---|
| 晨钟修道院 | 汤姆（修道院军需官） | 石像鬼、植物 |
| 金穗镇 | 杜克（治安官） | 鼠人、蛙人、野猪、稻草人 |
| 晴岚港 | 布雷克（港务长） | 灰巾帮（bandit / bandit_d） |
| 冒险者公会 | 葛雷森（会长） | 鬣人、鸟妖 |
| 以太学者会 | 赛琳娜（蔚蓝之塔） | 傀儡、蜘蛛 |

成员 NPC 名单写在 `DataRep.factions()[fid]["npcs"]`，`DB.npc_faction` 是反查索引；
怪物家族 → 阵营写在 `"fams"`，索引为 `DB.fam_faction`。不属于任何阵营的 NPC（路人、守卫的临时单位）没有关系条。

## 关系等级

| 等级 | 累计点数 | 阵营商人折扣 |
|---|---|---|
| 中立 | 0 | 无 |
| 友善 | 500 | 5% |
| 尊敬 | 1500 | 10% |
| 崇敬 | 3000 | 15% |
| 崇拜 | 5000（上限） | 20% |

界面显示的是**本级区间进度**（如 尊敬 300 / 1500），不是累计值。

## 来源

| 来源 | 规则 |
|---|---|
| 任务交付 | `(40 + 8×任务等级) × 任务权重`，归到**交付 NPC** 所属阵营；`quest["rep"] = {阵营: 点数}` 可覆盖 |
| 击杀 | `等级 × 0.6`，精英 ×1.5、稀有/命名 ×3、首领 ×5；按怪物 `fam` 归属；小动物不给 |
| 副本首领 | 怪物数据里的显式 `"rep"`：守钟人 维克托 +400 晴岚港、双枪莱克 +300 晴岚港、腐根守卫 厄尔班 +300 晨钟修道院 |

击杀声望默认不逐条播报，只在**升到新等级**时播报；任务声望逐条播报并显示本级进度。

## 军需品

货单条目支持三种写法：`"物品id"`（无门槛）、`{"id": …, "rep": [阵营, 等级]}`（声望门槛）、
`{"id": …, "price": 覆盖价}`。门槛等级 1–4 对应 友善 / 尊敬 / 崇敬 / 崇拜。

| 货单 | 友善 | 尊敬 | 崇敬 | 崇拜 |
|---|---|---|---|---|
| qm_abbey | 巨熊之锁甲护肩 | 苍鹰之单手锤 | 夜枭之宝石项链、**缰绳：晨露白鹿** | — |
| qm_goldshire | 灵猴之硬皮护腿 | 猛虎之单手剑 | 巨熊之锁甲战靴 | — |
| qm_city | 夜枭之披风 | 巨熊之锁甲 | 猎隼之指环 | 猛虎之双手剑（紫） |
| qm_guild | 灵猴之腰带 | 猎隼之火枪 | **缰绳：灰巾座狼** | 巨熊之护符（紫） |
| qm_tower | 夜枭之兜帽 | 苍鹰之法杖 | 智慧之副手 | — |

每张货单另有 1–2 件无门槛的补给（药水、食物、白装），保证军需官一开始就有东西可买。
两件坐骑缰绳（晨露白鹿 / 灰巾座狼）见 `docs/坐骑系统.md`；学习它们还需要先学初级骑术。
军需品价格与普通商品一致（`物品价 × 4`），再乘上该阵营的声望折扣。

## 接入点

| 位置 | 作用 |
|---|---|
| `Game.turn_in_quest()` | 交付任务后按阵营结算声望 |
| `Game.on_kill(mob_id, level)` | 击杀后按家族或显式 `rep` 结算声望（`mob.gd` 传入实例等级） |
| `Rep.gain()` | 统一入口：封顶 5000、升级播报、发 `Game.rep_changed` |
| `win_char.gd::_refresh_rep()` | 角色面板右侧的声望条（每阵营一行：名称 / 等级 / 进度条 / 数值） |
| `win_npc.gd::_render_gossip()` | 阵营 NPC 对话显示当前关系；军需官多一个「军需品」入口 |
| `win_npc.gd::_render_vendor()` / `_buy()` | 货单条目渲染、门槛判定与文案、折扣价 |
| `_price()` | 普通商人与军需品统一走声望折扣 |

存档：`pd["rep"] = {阵营: 累计点数}`，老存档自动补齐，不升存档版本。

## 边界

- 没有敌对阵营（灰巾帮只作为声望来源，不可交互），也没有 PvP 声望。
- 声望不影响任务可接取条件（未做「需要声望 X 才能接」的门槛），只影响货单与折扣。
- 未做：声望徽章/战袍奖励、按等级解锁的称号、声望衰减。
