## 2. 地表与建筑贴图（已接入）

来源：`E:\codexwork\洛奇mobile\assets\terrain\`（堤尔克那地表）、`assets\dungeons\`（Alby 地下城）、
`assets\textures\`（堤尔克那建筑图集）。

改编原则（`tools/reftexture/adapt_textures.py`）：
- **只取参考贴图的笔触/图案，不带入它的配色**：细节层 = 参考图亮度 − 自身平均值；
- 地表贴图是彩色的（着色器里还要乘区域色调 `tint(col/d)`），所以输出 = **本项目原贴图的平均色 × (1 + 细节 × 强度)**；
  平均色不变 → 地面整体明度与色相不变，只多了手绘笔触；
- 建筑贴图按项目约定必须是**灰度、均值 0.5**（`U.BTEX` / `prep_tex.py`），因此输出 = **0.5 + 细节 × 强度**；
- 图集里裁出来的块用 `wrap_blend()`（滚动半幅 + 边缘带混合）做成无缝，比镜像拼贴更保形（木板/瓦片条纹方向不被打乱）；
- 裁块坐标用 `tools/reftexture/grid_atlas.py` 画出 128px 网格后人工核对，避免把门/箱子/装饰裁进去。

## 3. 未采用的部分（记录原因）

- **树木模型**：参考包里成型的树是 `Tree_00/01.obj`（437/484 KB，无明显 LOD）与图集化的
  `village/models/s*.glb`（220+ 个编号模型）。本项目现有树是刚校准过的绘本风（Quaternius CC0 + 自绘叶片遮罩，
  近景 `.scn` + 120m 外代理 LOD）。直接换成参考树会推翻这套 LOD 与叶色体系，
  且需要改生成器（`gen_vale.gd` 等）重新出图，本轮不动；**下一步**可挑 2–3 棵参考树，
  按 `tools/prepare_storybook_nature.gd` 的流程重建（重算法线、顶点色、代理 LOD）后作为**新变体**加入
  `VEG` 表（只需把变体数 +1，不必改地图数据）。
- **角色 / NPC 模型**：参考包里有 Tarlach、Warrior 的带动画 GLB 与染色贴图，属于商业客户端角色，
  与本项目程序化角色的骨骼 / 换装体系不兼容，仅作视觉参考。
- **`F:\MabinogiMobile_TW\appdata`**：是加密 AssetBundle（871 个 `.blob`），未解包，本轮未用。
- `assets/audio/` 里另一轮会话留下的探针文件（`_probe*.ogg/.wav`、`_blk.ogg`、`_one.ogg`、
  `bgm/town_day.ogg`）已移到 `.local/audio_probe_leftovers/`，未删除。
