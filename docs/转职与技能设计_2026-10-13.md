# 转职与技能设计（2026-10-13）

本文保留为历史设计底稿。用户已否决这一版的技能协同、资源管理和战斗表现；下文数值与循环不能作为当前实现要求。当前设计、独立职业量谱与验证依据见[职业循环重做与量谱](职业循环重做与量谱_2026-10-13.md)。

## 0. 数值基线（必须遵守）

| 项 | 15 级 | 20 级 | 来源 |
|---|---|---|---|
| 同级普通怪血量 | 300 | 480 | `DataMobs.HP_TABLE` |
| 同级怪单次伤害 | ≈ 23 | ≈ 31 | `DataMobs.base_dmg` |
| 旧版单发火球 | 68–88 | 101–127 | `fireball` 旧 rank |

设计规则：

- 一个普通填充技能（无冷却）打掉同级怪血量的 **4%–7%**，约 14–20 发打死一只。
- 一个有冷却的爆发技能 **12%–20%**。
- 终结技 / 大招 **25%–35%**，冷却不低于 30 秒。
- 持续伤害的总量按同级怪血量的 **10%–25%** 计。
- AOE 单目标伤害为单体技能的 **50%–60%**。
- 吸血 / 治疗以自身最大生命值的百分比表达，不用绝对值。

> 前几轮写入基础职业的技能（火球 280–340、炎爆 600–700、致死打击 500–700 等）是这个基线的 3–5 倍，会在实现转职技能时一并回调，并由测试断言。

## 1. 通用机制（已有 / 待做）

已有：连招链 `combo_chain`、`add_charge`（火 / 冰）、`add_mark`（圣 / 暗）、`momentum`（势能）、`stamina`、`dodge`、`teleport_behind`。

待做（本设计需要）：

1. **属性量表 `gauges`**：每个单位一个 `{名称: 数值}` 字典，替代为每个职业各加一个变量。用于：冰印记、光量表 / 雷量表、怒气（狂战士）、风 / 水量表等。
2. **印记 `marks`**：与量表相同的存储，区别是层数（整数）和过期时间。冰印记用它。
3. **条件加速 `cast_cut`**：技能带 `cast_by_gauge`，按某个量表层数缩短咏唱。
4. **盾反 `riposte`**：被攻击瞬间有盾牌反击窗口，窗口内格挡成功触发一次反击。
5. **吸血 `lifesteal`**：伤害按比例回复自身生命。
6. **附魔 `enchant`**：自身 buff，使普攻附带某属性伤害（圣职者、魔法剑士）。
7. **量表转移 `transfer_gauge`**：把 A 量表按比例转到 B 量表。

## 3. 黑魔法师（火 / 冰 / 暗）

循环：冰系技能免费、回复法力并积累「印记·冰」（最多 5 层）；火系技能耗法力，每层印记缩短下一发火系咏唱 10%（最多 50%，施放后清空）；暗系技能是爆发与填充。

| 技能 | 属性 | 类型 | 15 级伤害 | 说明 |
|---|---|---|---|---|
| 霜刺 | 冰 | 填充 | 30–36 | 免费，回复 8% 法力，+1 印记·冰 |
| 冰枪 | 冰 | 瞬发 | 24–30 | CD 6s，+2 印记·冰，减速 |
| 烈焰弹 | 火 | 主输出 | 62–76 | 耗法力，咏唱 2.0s，吃印记缩短 |
| 炎爆 | 火 | 大招 | 118–140 | 耗法力，咏唱 3.0s，CD 18s，附 6s 灼烧（总计 36） |
| 焚风 | 火 | AOE | 36–44 | 8 码，咏唱 1.5s，CD 10s |
| 暗影箭 | 暗 | 填充 | 44–54 | 瞬发，耗法力，无冷却 |
| 虚空脉冲 | 暗 | 爆发 | 96–116 | CD 20s，消耗全部印记·冰，每层 +10% |
| 灵魂榨取 | 暗 | 回复 | 32–40 | 引导 3s，回复 20% 法力，目标低血时翻倍 |

被动：禁忌知识、侵蚀（已在 `DataSpecs`）。特性：汲取（已有）。

## 4. 元素法师（水 / 雷 / 光）

循环：水系技能给自己上「潮涌」（护盾 + 减伤 + 回复），雷系技能在潮涌下伤害提高并带连锁；光系用于净化与支援。伤害整体低于黑魔法师约 20%。

| 技能 | 属性 | 类型 | 15 级伤害 | 说明 |
|---|---|---|---|---|
| 水弹 | 水 | 填充 | 28–34 | 免费，+1 潮涌 |
| 潮汐护盾 | 水 | 自身 | 吸收 80 | CD 25s，持续 15s，吸收期间回复法力 |
| 浪涌 | 水 | AOE | 30–38 | 8 码，CD 12s，击退 + 减速 |
| 雷击 | 雷 | 瞬发 | 52–64 | CD 4s，潮涌下 +30% |
| 连锁闪电 | 雷 | 连锁 | 44–54 | 咏唱 1.5s，弹跳 3 个目标，每跳 -20% |
| 雷暴 | 雷 | AOE 大招 | 78–94 | CD 30s，8 码，潮涌层数每层 +8% |
| 圣光束 | 光 | 支援 | 治疗 70–86 | 友方治疗 / 对敌方造成伤害 |
| 净化之光 | 光 | 自身 | 驱散 | 驱散自身 / 友方 1 个减益，CD 12s |

被动：元素共鸣、灵动。特性：导电（已有，改为按潮涌层数触发）。

## 5. 圣骑士（战士）

循环：持盾格挡 → 盾反窗口 → 反击；守护队友分担伤害。

| 技能 | 类型 | 说明 |
|---|---|---|
| 盾击 | 填充 | 盾牌伤害，高威胁，+1 神圣之力 |
| 盾反 | 反击 | 被攻击前 0.5s 内使用，格挡成功后触发反击伤害并眩晕 |
| 圣盾 | 自身减伤 | 减伤 40%，8s，CD 90s |
| 守护 | 队友保护 | 分担选中队友 30% 伤害，10s |
| 圣光冲击 | 远程 | 神圣之力满时释放，伤害 + 治疗自身 |

## 6. 狂战士（战士）

循环：攻击 / 被攻击积攒怒气 → 消耗怒气打单体爆发；部分吸血。

| 技能 | 类型 | 说明 |
|---|---|---|
| 斩裂 | 填充 | +12 怒气 |
| 嗜血斩 | 消耗 | 30 怒气，吸血 20% |
| 狂乱 | buff | 攻速 +25%，受伤 +10%，12s |
| 处决 | 终结 | 低血翻倍，吸血 35% |
| 铁血冲锋 | 位移 | 突进并 +20 怒气 |

## 7. 白魔法师（牧师）

风 / 水 / 光，治疗职业。

| 技能 | 属性 | 类型 | 说明 |
|---|---|---|---|
| 清风疗愈 | 风 | 快速治疗 | 咏唱 1.2s |
| 潮汐祝福 | 水 | HOT | 12s 持续治疗 |
| 光辉庇护 | 光 | 护盾 | 吸收 + 小治疗 |
| 疾风术 | 风 | 增益 | 全队移速 +20% |
| 圣光大治愈 | 光 | 大治疗 | 咏唱 2.5s |

## 8. 圣职者（牧师）

双手锤坦克，光量表 + 雷量表。

- 主循环：重击同时积攒光 / 雷量表
- 光量表：用于治疗与保护技能
- 雷量表：附魔自身（普攻附带雷伤害）、释放伤害技能
- 特定技能可强化其中一个量表，或把光 ↔ 雷按 50% 转移

## 9. 刺杀者 / 魔法剑士（盗贼）

- 刺杀者：沿用现有盗贼技能，补隐身开场、毒、出血
- 魔法剑士：细剑 + 暗属性 / 无属性魔法；近战填充 + 魔法爆发；暗属性附魔

## 10. 枪炮师 / 机甲师（枪手）

- 枪炮师：多种枪械切换（步枪 / 霰弹 / 手炮），AOE + 远距离单体，保留机械猎犬
- 机甲师：外骨骼，近中程单体，较强的自身强化，无猎犬
