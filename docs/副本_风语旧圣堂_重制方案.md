### 场所与主线

风语旧圣堂原是一座依山修道院：南侧接待朝圣者，西侧修士种植药草，正殿下方储藏酒粮，东侧服务院负责转运，北侧正殿礼拜，西北守钟高台负责敲钟。灰巾帮利用地下转运通道占领东翼，腐根侵入药园，圣歌看守与守钟人留在宗教核心。

```text
南山门 → 朝圣前庭 → 西侧药园回廊 → 腐根花园（厄尔班 / 火种 I）
                                           ↓ 根须栅门
                 旧墓廊 → 正殿下方储藏层 → 装卸前平台
                                                      ↓
                                  灰巾装卸院（莱克 / 火种 II）
                                                      ↓ 东翼门
                    上行侧翼 → 东耳堂 → 圣歌祭坛（阿尔诺 / 火种 III）
                                           ↓ 回到西耳堂
                         三火种守钟门 → 折梯 → 石桥 → 丧钟高台（维克托）
```

入口前庭直接望向正殿与高处钟楼。坍塌正阶形成清楚的封闭边界，完整西廊提供下一步方向。沿药圃外围绕行具有生活区依据；正殿下方的地窖与上层礼拜空间形成真正的上下关系。到达东翼楼梯平台时回看装卸院，进入耳堂时揭示尽端祭坛，终局高台再回望整座修道院。

祈愿侧堂是前庭旁的短可选支路，内容仅限祈愿、文本或普通补给；必需火种全部在明确主线上。击败第三首领后回到耳堂的短段用于离开祭坛并进入守钟门，避免全图跑回中庭。

## 设计依据

`Dungeon Architect 1.22.0.unitypackage` 是 Unity 编辑器插件，包含 GridFlow、SnapGridFlow、RoomDesigner、Door Categories 和 Visibility Graph 等系统。它的 Unity 场景、Prefab、MonoBehaviour 和 GUID 引用不能直接导入 Godot，因此本项目借用它的设计方法，在 Godot 的 `ZoneBuilder`、`Prop`、`MobSpawner` 和数据驱动战斗上实现同等的房间图与门控。
