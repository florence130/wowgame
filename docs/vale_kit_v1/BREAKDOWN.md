# 构件、工法和接口

统一风格：用户色板 v1；厚实轮廓、克制细节、手绘卡通、柔和真实阴影。用户已允许农舍和谷仓重设计。

用户最新要求墙面为砂石颗粒、红砖为多孔粗糙表面，整体不应反光。build008起全材质roughness1/specular0，矿物墙材质带albedo与内嵌切线法线。贴图包含同色系明暗，离散色板精确检查仅适用于纯色材质。主墙尺寸不计屋面下的闭合填充；山墙以实际屋面斜率闭合，避免按墙宽与屋宽两种坡度产生透缝。

| 手法 | 实际构件 | 可检查实现 |
|---|---|---|
| 01 镜像 | 农舍陶瓦屋顶 | Y 方向 Mirror，保留可编辑修饰器 |
| 02 阵列 | 陶瓦行、脊瓦、曲线围栏 | 定距 Array；弯栏先阵列后 Curve |
| 03 轮廓/分层挤出 | 墙体、拱门、窗框、梁、门廊、屋面底层 | 封闭轮廓挤出和分层几何；真实布尔开洞 |
| 04 实体化 | 屋面、连续覆草层、帆布 | Solidify；覆草层每坡连续，外缘独立圆厚收口 |
| 05 曲线倒角 | 门环、绳、挂钩、桶箍细节 | 曲线 bevel_depth；GLB 转实际网格 |
| 06 旋绕 | 草脊初版、木桶、花盆、风车轴 | Screw；最终草脊改为带定向UV的环形放样，草脊初版不作为质感验收 |
| 07 曲线变形 | 12m 弯曲围栏 | 正X定距 Array → Curve，路径对象保留 |
| 08 桥接/放样 | 四层收分八角塔身、塔帽、最终草脊 | 相邻截面环桥接形成闭合网格 |
| 09 简单形变 | 风车帆布 | 少量 Twist，实体化后导出；不做夸张扭曲 |
| 10 几何顶点 | 连续草层、花朵、木筋、玻璃、屋面尖梢 | 直接顶点/面构造；不是借此替代其它九种 |

CSG 初体保留为 stages/STAGE_01_CSG.glb。解析 SDF 初样与改良批次为 STAGE_02_SDF_initial / STAGE_07_SDF_refined_batch，来自解析距离场采样、行进四面体，不是 voxel remesh。规则接口保持确定尺寸；SDF 石块用于风车脚部石裙。

农舍墙体12×9×6m，谷仓16×11×8m（墙高，不含屋顶），风车塔身6m直径/14m高；屋面和门廊另计。农舍层高3m，谷仓层高4m，不统一拉伸整栋。独立模块默认4m横向节距；depth/height等参数见build.py。机器可读实际外包和socket见构建manifest.json。

坐标：Blender X右、Y前、Z上；导出Godot X右、Y上、-Z前。所有完整建筑底面基准0；风车转子例外，以轴心0为原点，安装于Blender(0,3.65,11.9)，在Godot(0,11.9,-3.65)绕Z旋转。帆布在塔体前，静态整栋版已含转子，不应重复添加动态转子。

接口：wall/beam/roof左右socket为(-2,0,0)/(2,0,0)；墙上接口z=3或4。屋面起伏和末梢不能用于吸附，使用底层实体边界。草顶中段无侧向圆厚包边，只有整栋外端生成包边，避免每4m形成一块瓦片。曲线围栏必须保留顺序Array→Curve。柱头/壁饰/窗框可穿入主体少量形成合理装配，门洞须在主体真实开孔。

质感失败与修复：用户否决build_002的金色硬片屋顶，随后也否决加纤维贴图后的片块构造。build_004与probe001被新要求替代，不能交付。当前thatch.py改为每坡连续覆草层，去除片格与横向瓦缝；外露斜边独立UV，圆厚檐口、少量参差草梢、roughness .97。详见THATCH_MATERIAL.md的逐版失败与修复证据。
