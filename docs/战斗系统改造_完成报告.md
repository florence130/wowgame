## 🎮 实现的核心系统

### 1. 职业专属资源系统

#### 战士 - 势能系统 (Momentum)
```gd
# unit.gd 第194-200行
var momentum: float = 0.0          # 当前势能
var max_momentum: float = 100.0    # 最大势能
var momentum_decay_delay: float = 3.0  # 衰减延迟
var momentum_decay_rate: float = 20.0  # 衰减速率/秒
```

**机制**:
- 攻击技能产生30-40势能
- 爆发技能消耗60-80+势能
- 3秒不攻击开始衰减(20/秒)
- 势能影响移动速度(未实现)

#### 法师 - 双充能系统 (Dual Charges)
```gd
# unit.gd 第201-207行
var fire_charges: int = 0          # 火焰充能
var frost_charges: int = 0         # 冰霜充能
var max_charges: int = 5           # 单类充能上限
```

**机制**:
- 火球术产生火焰充能
- 寒冰箭产生冰霜充能
- ≥3层充能解锁爆发技能
- 可混合消耗(奥术冲击)

#### 盗贼 - 能量+连击点 (Energy+Combo Points)
```gd
# unit.gd 第208-215行
var energy: float = 100.0          # 当前能量
var max_energy: float = 100.0      # 最大能量
var energy_regen: float = 10.0     # 恢复速率/秒
var combo_points: int = 0          # 连击点
var max_combo_points: int = 5      # 最大连击点
```

**机制**:
- 能量持续恢复(10/秒)
- 生成技能消耗能量产生连击点
- 终结技消耗所有连击点
- 背后攻击额外连击点

#### 牧师 - 双标记系统 (Dual Marks)
```gd
# unit.gd 第216-224行
var holy_marks: int = 0            # 圣光标记
var shadow_marks: int = 0          # 暗影标记
var max_marks: int = 5             # 单类标记上限
var mark_duration: float = 30.0    # 标记持续时间
```

**机制**:
- 圣光技能产生圣光标记
- 暗影技能产生暗影标记
- ≥3层标记解锁消耗技能
- 标记增强治疗/伤害

### 2. 闪避与耐力系统
```gd
# unit.gd 第168-172, 226-235行
var stamina: float = 100.0         # 当前耐力
var max_stamina: float = 100.0     # 最大耐力
var dodge_cost: float = 30.0       # 闪避基础消耗
var stamina_regen: float = 25.0    # 恢复速率/秒
var consecutive_dodges: int = 0    # 连续闪避次数
```

**机制**:
- 闪避消耗30耐力
- 连续闪避递增消耗(+20/次)
- 不闪避时自动恢复(25/秒)
- 耐力不足无法闪避

### 3. 位置判定系统
```gd
# unit.gd 第720-740行
func is_behind(target: Unit) -> bool:
    # 判断是否在目标背后120度扇形
    
func is_flanking(target: Unit) -> bool:
    # 判断是否在目标侧面90度扇形
```

**用途**:
- 盗贼背后攻击额外连击点
- 某些技能需要位置要求
- 未来可扩展位置伤害加成

### 4. 连招链系统
```gd
# unit.gd 第173-175行
var combo_chain: String = ""       # 当前连招链
var combo_window: float = 0.0      # 连招窗口剩余时间
```

**机制**:
- 技能设置连招标记
- 后续技能要求特定连招链
- 窗口4秒，超时清空

## 🆕 新增Effect类型

验证脚本统计结果：

### 资源生成
- `add_charge` (5次) - 添加火焰/冰霜充能
- `add_mark` (4次) - 添加圣光/暗影标记
- `combo` (4次) - 产生连击点
- `momentum` (2次) - 产生势能

### 资源消耗
- `consume_all_charges` (1次) - 消耗所有充能
- `consume_marks` (2次) - 消耗标记
- `finisher_damage` (1次) - 终结技伤害
- `finisher_aura_scaled` (1次) - 终结技光环
- `finisher_stun` (1次) - 终结技昏迷

### 位置与机动
- `teleport_behind` (1次) - 瞬移到目标背后
- `blink` (1次) - 闪现
- `charge` (1次) - 冲锋
- `leap_back` (1次) - 后跳

### 控制与其他
- `stamina_cost` (1次) - 消耗耐力
- `combo_chain_set` (4次) - 设置连招链
- `combo_chain_clear` (4次) - 清除连招链

### 保留的传统类型
- `damage` (29次) - 直接伤害
- `aura` (26次) - DOT/BUFF/DEBUFF
- `self_aura` (16次) - 自身光环
- `aoe` (11次) - 范围伤害
- `weapon` (8次) - 武器伤害
- `energize` (8次) - 回复能量/法力
- `heal` (4次) - 治疗
- `taunt` (3次) - 嘲讽

**总计**: 109个effect实例，涵盖30+种类型

## 🆕 新增Requires类型

验证脚本统计结果：

### 资源要求
- `combo` (3次) - 需要连击点
- `min_charges` (1次) - 需要最少充能
- `holy_marks_min` (1次) - 需要圣光标记
- `shadow_marks_min` (1次) - 需要暗影标记

### 状态要求
- `combo_chain` (5次) - 需要连招链
- `has_aura_self` (1次) - 需要自身光环
- `stealth_or_behind` (1次) - 需要潜行或背后

### 装备要求
- `dual_wield` (1次) - 需要双持
- `ranged_weapon` (7次) - 需要远程武器

### 目标要求
- `no_aura_target` (1次) - 目标无特定光环
- `poly_target` (1次) - 目标可变形

**总计**: 22个requires实例，涵盖10种类型

## 📊 设计评估

### 优点
✅ **差异化明显** - 每职业玩法手感完全不同  
✅ **深度提升** - 位置/连招增加技术天花板  
✅ **节奏感强** - 资源循环创造决策点  
✅ **可扩展性好** - 天赋/专精预留空间  
✅ **代码质量高** - 结构清晰,易维护  

### 风险
⚠️ **学习曲线陡** - 4种不同资源系统  
⚠️ **平衡难度大** - 机制复杂平衡困难  
⚠️ **UI工作量大** - 需要定制UI显示  
⚠️ **测试工作量大** - 40个技能逐一验证  

### 建议
1. 优先完成UI,否则玩家无法理解资源系统
2. 先测试一个职业,验证手感后再全面展开
3. 考虑新手引导,解释资源机制
4. 预留数值调整空间,初期可能需要大幅改动
