# 战斗与15级转职

2026-10-13更新：技能循环与资源已重做，特殊量表使用独立职业量谱。完整收支、原生样张和测试依据见[职业循环重做与量谱](职业循环重做与量谱_2026-10-13.md)。历史设计底稿和早期接力日志不能代表当前技能行为。

正式游戏从根目录“启动最新游戏.cmd”进入。N打开转职页；15级首次转职免费，换职需脱战且施法/动作结束，费用20银。新技能自动进入技能书与动作条，1至=使用第一排、Shift加对应键使用第二排，具体以动作条绑定为准。

换职清空旧量表、附魔、盾反窗口与职业增益，移除不兼容技能。失去穿戴资格的装备移回背包；空间不足会阻止换职，不扣钱、不丢装备。旧存档职业ID保留，`shadow_priest`显示圣职者，`duelist`显示魔法剑士，`marksman`显示枪炮师，`gadgeteer`显示机甲师。天赋树和旧天赋点不再参与玩法。

## 看懂量谱与技能接续

职业量谱在技能条左上、聊天框上方，使用专用图形和连携提示。生命框显示生命、普通法力/能量/耐力。资源足够时量谱高亮消耗机会，实际施放仍取决于距离、目标、冷却和角色状态。

## 动作与机制

近战技能按2.4码有效距离检查，短前摇结束时仍需目标活着、距离/视线有效，资源在接触/发射时支付。翻滚可取消未命中攻击和读条，未支付资源保留，不会白得伤害。GCD/施法/动作结束前0.22秒可缓存一次输入，保留原目标；死亡目标、过期输入或被控制时丢弃。

翻滚花30耐力，连续使用每次额外20，移动最多3.8码，短闪避窗口0.18秒。DOT、坠落及明确Boss范围机制穿透这个窗口。翻滚、冲锋、影步、闪移和后撤沿物理碰撞移动，不穿墙、不跨楼层；定身阻止位移。盾反只挡一次近战，不能挡范围机制。

Boss免疫眩晕、定身、恐惧与瘫痪；只可打断明确可打断的技能，丧钟回响保留可打断。驱散保留不可驱散机制标记。减伤叠加仍保留至少35%伤害乘数，护甲/护盾/队友分担另行结算。

命中使用角色局部短停顿、接触小火花、命中音和轻微镜头偏移，Boss及世界计时持续运行。枪械以武器发射点产生反馈，机甲使用装甲武器；换弹姿态和近战收招已修正。转职前战士蓄势待发仍是真正的三次引导，每0.5秒15势能、完整45，可70%速度移动，中断仅保留完成的部分。

## 独立试玩与验证范围

运行根目录“启动转职试战.cmd”进入十职业独立试战，或Godot打开 `tests/job_arena.tscn`。左侧按钮重建测试角色；使用正式Player输入、动作、技能与HUD，W/S、Q/E移动，Tab选敌，动作条翻滚。白魔默认选中训练队友，点击队友框也可选择，队友持续掉血供治疗测试。训练首领有普通近战和8码预警攻击。测试角色不读写真实存档。

本轮验证包括237脚本加载、123项转职/边界回归、64项技能协同/动作回归、各90秒的十职业持续循环和原生连续帧。循环包含四次中断/停顿，无中途资源或冷却重置；白魔承受实际治疗压力。数值、截图与自动输入不等于真人手感认可或完整副本平衡。原生渲染退出仍有资源释放告警。

正式圣堂全流程上一轮停在1/37路点，未进入Boss；本轮未修地图路径，不能声明四首领全流程通过。真实Boss践踏结算另有直接回归，翻滚和盾反不会免疫它。多人同步与正式导出尚未验证。
