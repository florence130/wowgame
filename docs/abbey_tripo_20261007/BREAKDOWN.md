# 晨露谷修道院：市政厅参考形制拆解

本轮以用户提供的蓝灰屋顶、浅色石墙、中央高塔与对称侧翼市政厅为形制参考，将建筑拆为可复用模块，供晨露谷修道院及其他建筑使用。第二张图只提供“先拆总成、再拆小件”的表达参考；其中树木、旗帜、庭园、路灯等不进入本轮构件库。

当前产物是**阶段 1：拆解、Tripo 造型参考包与工具接入原型**。下面的构件 ID、尺寸和制作路线是本轮设计规格，不代表已经完成相应 Blender 模型。现有 `abbey_kit_v3/build005` 的 59 类模型是旧教堂、钟楼与回廊库，可复用其工具和部分结构；不是本图市政厅的已完成模型。

## 范围与依据

- 保留建筑需要的墙、门窗、立柱、梁、楼板、天花、屋面、檐口、牛腿、楼梯、平台、护栏和塔身。
- 去除树木、灌木、草坪、旗帜、徽章、十字、花园、路灯及其他附属装饰。屋顶最高点采用普通建筑收头，不能把旗杆或十字作为结构继续保留。
- 参考图可支持正面比例与主要轮廓判断；背面、建筑进深、屋面排水、内柱网、内楼梯、楼板、梁与天花均无直接图像依据，下文标为**设计补全**，后续需按空间与受力关系建模。
- 所有数值均为本轮建议设计尺寸，单位米；不是从图片量测的结果。先建立统一开间，再根据整体比例调整，不按参考图像素直接宣称真实建筑尺寸。
- 不要求每个零件同时使用十种手法。每件从十种基础手法中选适合的组合，保留实际源参数、修改器或网格构造证据。

## 制作手法与路线编码

| 编码 | 十种基础手法 | 适用方式 |
|---|---|---|
| M1 | 镜像 | 半件保持中面；另一侧由 Mirror 或明确的几何镜像生成 |
| M2 | 阵列 | 按测量节距重复，不用非均匀缩放拉长整个模块 |
| M3 | 轮廓/分层挤出 | 截面、门窗轮廓、线脚与阶梯体 |
| M4 | 实体化 | 开放面壳加厚；接缝厚度需单独核对 |
| M5 | 曲线倒角 | 沿路径扫掠线脚、窗棂和圆形杆件 |
| M6 | 旋绕 | 柱础、圆柱、栏杆柱和塔盘；保留截面配方 |
| M7 | 曲线变形 | 可选弧形护栏/连续装饰变体；直段无需使用 |
| M8 | 桥接/放样 | 连接多个截面环，形成塔顶、渐变柱与拱面 |
| M9 | 简单形变 | 可选轻微木梁弯曲；精确拼接面仍校正回平面 |
| M10 | 几何顶点 | 确定性网格构造、局部轮廓调整、端面校正 |

CSG 是额外的实体布尔/几何拼装路线，不计入这十种手法。SDF 是由解析距离场采样生成体积表面的路线，不能把体素 Remesh 或 Tripo 输出称为“纯 SDF”。

- **H / 精确结构**：CSG 或直接网格体量 → 十法精修 → 开口/接口校正。薄片、门窗和拼接边不转 SDF。
- **S / 厚石件**：CSG 体量对照 → 解析 SDF 粗样 → 细采样与局部精修 → 硬接口校正；按需要保留 CSG 成品作比较。
- **T / 可选 Tripo 探索**：所有六件默认走 H 原生 Blender 路线。若需要额外造型探索，可用单件参考生成候选，再导入、校准、检查并重建结构接口；若后续另做解析 SDF，必须另留距离场源。Tripo 网格本身不是 SDF 阶段证据。
