# 坐骑

2026-10-08。数据 `src/data/data_mounts.gd`、逻辑 `src/core/mounts.gd`、界面 `src/ui/win_mounts.gd`。
入口：底栏「坐骑」按钮 / J 键。骑术与坐骑召唤技能原本就有（`pd["riding"]`、`Unit.mounted`、`Unit.move_speed()`），
本轮把「一个模型 + 一个速度」的写死实现扩展成**可收集的坐骑表**，并补了收藏界面与获取途径。

## 坐骑表

| id | 名称 | 模型 | 速度 | 获取方式 |
|---|---|---|---|---|
| horse | 高地骏马 | horse | +60% | 马厩商人（罗恩 / 马修）出售「缰绳：高地骏马」 |
| deer | 晨露白鹿 | deer | +60% | 晨钟修道院 · 崇敬（军需官 汤姆的货单） |
| wolf | 灰巾座狼 | wolf | +75% | 冒险者公会 · 崇敬（军需官 葛雷森的货单） |
| mech | 魔导机车 | mech | +80% | 主线《晴岚港的新市民》奖励 / 交易所稀有货 |
| bear | 铁鬃战熊 | bear | +90% | 成就「成就猎人」（100 点成就点数）奖励 |

坐骑 = **召唤技能**（`spell`，效果 `{"type": "mount", "mount": 坐骑id}`）+ **学习物品**（`item`，`use.learn = 技能`）。
学会技能即视为已收集，所以收藏状态直接看 `pd["spells"]`，**没有新增存档字段**（老存档天然兼容）。

## 规则

| 项 | 行为 |
|---|---|
| 骑术门槛 | `pd["riding"]`；10 级后在马厩商人处以 5 银学「初级骑术」 |
| 学习 | 使用缰绳/钥匙类物品：没学骑术会报错且**不消耗物品**；学会后物品消失、技能进技能书并自动上条 |
| 召唤 / 收起 | 召唤是 1.5 秒读条（战斗中不可用）；已在骑乘同一坐骑时再次使用即下马 |
| 下马时机 | 进入战斗、游泳、阵亡、传送、坐船/列车、进食 |
| 速度 | `Unit.move_speed()` = 基础速度 × (1 + 该坐骑速度 + 各类加速)；下马后回到 100% |
| 他人 | 同伴（`ally.gd`）在主人骑乘时会以 1.5 倍基础速度跟随，保持队形 |

## 接入点

| 位置 | 作用 |
|---|---|
| `Unit._mount(id)`（效果分发） | 坐骑效果 → 玩家 `_mount()`；`DataMounts.from_effect()` 兼容旧的 `"model"` 写法 |
| `Player._mount(id)` | 建 `CreatureModel`、记录 `mount_id` / `mount_bonus`、把角色抬到坐骑背上 |
| `Unit.move_speed()` | 用 `mount_bonus` 代替原先写死的 +0.6 |
| `Player.use_bag_item()` | `use.learn`：骑术门槛判定 + 学习（原有逻辑，本轮只保证坐骑物品走通） |
| `Game.learn_spell()` | 学会后重判成就（技能数 / 坐骑收藏） |
| `Achieve` 的 `mounts` 判定 | 收藏数 = 已学会的坐骑召唤技能数；三档成就（1 / 3 / 5 个） |
| `DataMounts.quality_color()` / `speed_text()` | 收藏簿里的品质配色与速度文案 |
| `IconView._glyph()` | 新增 `deer` / `wolf` / `bear` 三个程序化图标；技能图标 `skills/mount_*.svg` |

## 边界

- 没有坐骑装备栏（鞍具/装饰）、没有坐骑专属技能（冲刺/跳跃）、没有速度叠加的递减规则。
- 坐骑模型沿用 `CreatureModel` 的程序化四足/机械体（白盒），未换精细模型。
- 坐骑不能在副本里召唤（副本内进战斗频繁，实际用不上）；飞行坐骑与飞行路线是另一套系统（`fly_to`）。
