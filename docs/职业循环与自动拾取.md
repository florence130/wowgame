# 职业循环、自动拾取与 UI 图标

2026-10-06。本轮保持 UI 布局，调整游戏行为和图标。后续用户反馈已纳入：法师一级只保留两个职业技能。

## 自动拾取

- 玩家或玩家宠物/同伴取得击杀归属后，金币和物品立即进入角色；无需右键尸体或打开拾取窗口。
- 可堆叠物品先补现有堆叠。背包装不下的余量进入角色 `pending_loot`，随现有存档一起保存。腾出空间时自动补入，并沿用获得物品提示与任务进度更新。
- 转交前清空尸体来源，重复交互、重复背包信号和区块离开/返回不能再次领取。
- 设置窗口原来的自动拾取选项位置改为状态说明；不再提供手动拾取模式。

## 职业基础循环

| 职业 | 基础手法 |
|---|---|
| 战士 | 蓄势斩免费产生12怒气 → 英勇打击消耗15怒气强化下一次普攻；保持自动攻击，穿插战斗怒吼 |
| 法师 | 火球术消耗法力输出 → 寒冰箭免费造成伤害、减速并恢复14%最大法力；成长后加入爆发/控场/调息 |
| 牧师 | 暗言术：痛持续伤害 → 惩击输出；免费灵光恢复12%最大法力，按需治疗 |
| 盗贼 | 邪恶攻击30能量积攒连击点 → 3–5点剔骨终结；剔骨消耗25能量，每点返还5能量 |
| 魔导枪手 | 免费稳固射击恢复12%最大法力 → 以太弹输出；自动射击与机械猎犬配合 |

普通伤害不再拖延玩家读条。移动取消施法、专门的打断技能及其封锁法术系、昏迷等控制机制保留。免费回蓝攻击在效果抵达目标时恢复资源，不要求伤害必定命中；目标在投射物抵达前死亡则不生效。

玩家法力自然恢复：战斗中最近消耗法力2秒内每秒恢复1%最大法力；之后至少2.5%或原精神恢复值；脱战至少8%。战斗中主动回蓝技能构成循环，脱战恢复减少饮水等待。

### 法师成长顺序

| 等级 | 可学习的新技能 |
|---|---|
| 1 | 火球术、寒冰箭（直接获得） |
| 2 | 火焰冲击 |
| 3 | 霜甲术 |
| 4 | 冰霜新星 |
| 5 | 造水术 |
| 6 | 寒流调息：3秒引导，共恢复54%最大法力，18秒冷却 |
| 7 | 魔爆术 |
| 8 | 奥术智慧、奥术飞弹、变形术 |
| 12 | 闪现术 |

后续技能沿用职业训练师学习规则，技能后续等级仍保留。一级火球术消耗20法力、读条1.5秒、基础伤害26–34；寒冰箭免费、读条1.5秒、基础伤害11–15。法师基础生命/法力从32/100调整为42/140（实际面板还包含耐力、智力等）。

旧角色载入时补齐缺失的一级循环技能，只填空快捷栏，不覆盖已知技能等级、已有栏位或装备。以前已学会的技能保留，不因本次调整没收；没有空格时从技能书拖入。

## 图标

新增59枚技能/通用动作图标、15枚 UI 图标。54枚职业技能都有独立图标，通用图标包含攻击和返程等。原创 SVG 使用有限色板、轮廓与分层色块；不是商业游戏提取素材，也不是 ChatGPT/API 生成位图。风格方向参考《洛奇 mobile》的简约符号和厚色块表达。

源文件：`assets/ui/icons/skills/`、`assets/ui/icons/ui/`；可复现生成器：`tools/build_ui_icons.py`。`IconArt`共享纹理缓存，`IconView`继续绘制热键、数量、冷却遮罩、不可用和悬停反馈。物品/未覆盖技能保留原有绘图回退。

接入快捷栏、技能书、训练师、拖拽预览、已匹配的增益图标、8个底部菜单及对应窗口标题。菜单仍为66×40，位置和间隔不变。职业操作说明放入技能提示、技能书说明的悬停提示和新角色欢迎消息，不新增面板。
