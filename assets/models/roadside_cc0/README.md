# Roadside low-poly props

Source: [Kenney Fantasy Town Kit 2.0](https://kenney.nl/assets/fantasy-town-kit), CC0 1.0 Universal. Source archive, observed license and download hash are retained in assets/third_party/kenney_fantasy_town.

The five runtime candidates are under rebuilt/. Native low-poly geometry is retained: cart 608 triangles, tall cart 1028, stall 106, bench 180 and banner 102. Rebuilt in tools/blender/rebuild_cc0_roadside.py: source palette texture replaced by grouped oak, dark iron, canvas and sage cloth; grounded feet and explicit meter heights. The game material-name contract applies its existing wood/plaster textures and material parameters. The raw imports and original palette are retained as source inputs, not claimed to have new authored topology.

The acquisition/rebuild does not itself establish placement, collision, visual or performance acceptance. Consult docs/gameplay-world-iteration-20261016.md for integration status and current evidence.
