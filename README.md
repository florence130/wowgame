# Canticum Turris · 高塔之歌

Godot 4.7.2 Mono + GDScript 的本地单机奇幻角色扮演游戏原型。包含角色创建、战斗与十种15级转职、任务、装备、城镇服务，以及晨露谷、潮风高地/晴岚港、风语旧圣堂三个正式区域。

## 克隆与运行

大型模型、贴图、音频及部分制作资料通过 **Git LFS** 保存。安装 Git 和 Git LFS 后克隆：

```powershell
git lfs install
git clone https://github.com/florence130/wowgame.git
cd wowgame
git lfs pull
```

使用 Godot 4.7.2 Mono 导入根目录 `project.godot`，等待资产导入完成，再运行主场景 `scenes/boot.tscn`。工程使用 Forward+ 渲染器。

本机的 `启动最新游戏.cmd` 和 `启动转职试战.cmd` 使用固定引擎路径；其他电脑可直接在 Godot 编辑器中运行，或替换脚本中的引擎路径。独立职业试战场景为 `tests/job_arena.tscn`，该场景不保存角色。

## 当前内容与验证

- 十转职共105个技能，其中2026-10-16新增40个战术、群攻、防御和打断技能。
- 分武器与学派的战斗反馈、空间战斗音效和落地脚步。
- 金穗镇道路、树冠留空、地面材质与低模摆件调整。
- 对应版本252个脚本加载无失败；15级绿装和原生三同伴条件下，圣堂58路点、16组怪、四首领连续流程通过。

当前仍是原型：城镇帧率偏低，快速传送压力检查曾触发Vulkan驱动超时；退出资源释放告警、部分场景美术、完整职业平衡和真人手感验收仍待改进。没有多人同步或正式发布验收。

详见[当前版本与更新记录](docs/当前版本与更新记录.md)、[本轮战斗、音效与场景说明](docs/战斗音效与场景_2026-10-16.md)和[长期迭代记录](docs/gameplay-world-iteration-20261016.md)。文档中 `.local` 与 `.shots` 路径指本机检查证据，临时产物未上传。

## 项目目录

- `src/`、`data/`、`scenes/`：正式代码、数据与场景。
- `assets/`：游戏资源、离线烘焙资源和来源/许可清单。
- `tools/`：Blender、地形、材质、音频与资产生成工具。
- `tests/`：原生机制、场景和渲染检查；部分历史检查依赖本机证据或素材路径。
- `docs/`：设计、制作资料和版本记录。

Godot导入缓存、历史备份、临时截图、导出成品、本机连接配置、对话归档、已弃用的两首客户端提取音乐，以及2.6GB未接入运行时的原始资源分发压缩包均排除在版本库外；本机文件保留。原第三方shader分发包亦不上传，当前工程着色器保留在源码目录。

第三方网站的原始HTML存档亦保留在本机，不上传其内嵌服务令牌；仓库保留资源、来源链接、许可证与加工清单。

项目使用多种来源的资源，各自遵循原许可证；仓库并未将第三方资产统一重新许可。CC0音效和模型、CC BY音乐等的作者、链接和处理记录保存在 `assets/third_party/`、`assets/source_packs/` 及相关资源目录。请按各来源许可使用，仓库公开不代表全部第三方资料可任意再分发。
