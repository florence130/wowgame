从城市中选择

点击建筑或左侧目录，调整位置、朝向与地基标高。

按住 Ctrl 可多选；选择街坊后，可整体移动与旋转。

所有修改自动保存在本机浏览器。完成后导出 JSON，可用于回导游戏。

草稿与游戏分开保存

此页面不会覆盖游戏文件。步行用于查看尺度与地面支撑，不代替游戏碰撞验收。

在晴岚港中调整布局

页面包含原生建筑模型、场景物件与地形，离线也可打开。

鸟瞰编辑
左键环绕，右键平移，滚轮缩放。单击建筑选择，双击建筑定位；F 聚焦当前选择。
步行漫游
点击画面后，鼠标转向，W A S D 行走，Shift 加速。Esc 释放鼠标；“鸟瞰编辑”返回编辑视角。
建筑与街坊
用面板数值或拖动手柄修改建筑。Ctrl/⌘ 多选，或从街坊菜单选择整组，再批量平移与旋转。复制、隐藏与删除均可撤销。
地面审查
隐藏建筑与装饰，查看预留占地、街坊步行网、道路、人行道与台阶。底面使用正式地面网格，轮廓来自同一总图；此模式只供审阅。
道路与台地
道路支持位置与宽度草稿，彩色带只表示改动意图。台地仅供查看，由统一地面总图调整，避免与街道、挡墙和入口脱节；旧草稿参数仍可保留并导出。
保存与回导
同一版本在本浏览器内自动保存。导出 JSON 包含完整布局、改动差异和基线标识，便于回导。另一版城市的草稿会被拦截，避免覆盖错误版本。

快捷键：Ctrl+Z 撤销 · Ctrl+Y 重做 · Delete 删除选中建筑
